# src/platform/linux

Linux x86·x64 product host backend와 별도 i386 production helper를 둡니다. `original_runner.cpp`는 두 제품 CLI를 `ExecutionBackend`에 연결합니다. `native_process_bootstrap.cpp`는 guard-page guest stack, 최소 TEB/PEB, FS selector와 signal fault context를 소유합니다. `native_ipc_host_probe.cpp`는 PE32 mapping·재배치·TLS·import gate event/reply, 제한된 stack memory IPC, pending import terminal stop과 구조화된 invalid-instruction fault를 합성 이미지로 검증합니다.

*This directory contains the Linux x86/x64 product-host backend and a separate i386 production helper. `original_runner.cpp` connects both product CLIs to `ExecutionBackend`. `native_process_bootstrap.cpp` owns the guarded guest stack, minimal TEB/PEB, FS selector, and signal-fault context. The Linux x86 product library also contains `native_in_process_runner.cpp`, selected only by explicit first-import and resolver diagnostic CLI options. `native_ipc_host_probe.cpp` validates PE32 mapping, relocation, TLS, import-gate event/reply, bounded stack-memory IPC, pending-import terminal stop, and a structured invalid-instruction fault with synthetic images.*

Linux POSIX 헤더는 이 플랫폼 디렉터리에서만 포함할 수 있습니다. 대소문자를 구분하는 파일 시스템 때문에 게스트 경로 해석은 `re2dj::hdd::HddRoot`를 반드시 거쳐야 합니다. synthetic native probe는 공용 `ImportDispatcher`로 import를 완료하고 `kStop`이 helper continuation 없이 terminal 상태가 되는지 확인합니다. 제품 경로에는 아직 실제 Win32 API binding이 없으므로 첫 미구현 import·process exit·guest signal fault에서 통제 정지합니다.

*Linux POSIX headers may only be included in this platform directory. Because the file system is case-sensitive, guest path resolution must always go through `re2dj::hdd::HddRoot`. The synthetic native probe completes imports through the shared `ImportDispatcher` and verifies that `kStop` becomes terminal without a helper continuation. The product path has no actual Win32 API bindings yet and therefore stops in a controlled way at its first unimplemented import, process exit, or guest-signal fault.*

이 디렉터리의 루트는 Linux 전용이면서 host 비트 폭 중립인 코드 또는 x86/x64 공용 코드용입니다. 두 폭이 함께 쓰는 PE mapping(`native_pe_image`), import thunk, `NativePeSession`, fault observation, `NativeInProcessRunner`가 루트에 있습니다. import handler 계약(`native_import_gate.h`), 게스트 fault 형태(`native_guest_fault.h`)도 루트에 있습니다. process bootstrap(`native_process_bootstrap.h`), import bridge(`native_import_bridge.h`), 4 GiB 미만 할당(`native_low_memory.h`)은 루트에 선언만 두고 폭마다 구현합니다. facade module image·set, dynamic thunk, kernel32 진단도 두 폭 공용으로 루트에 있습니다(작업 355). 게스트 SEH 디스패치 판단(`native_guest_seh`), instruction trace(`native_instruction_trace`), GetVersion 진단도 두 폭 공용입니다(작업 356). `x86/`에는 i386 직접 실행 구현이 있습니다(i386 helper는 작업 379에서 제거). `x64/`에는 x86-64 프로세스 안에서 CS `0x23` compatibility mode로 게스트를 실행하는 전환 runtime(`native_compat_mode*`), 그 위의 bootstrap·bridge 구현, 합성 probe가 있습니다([작업 353](../../../docs/design/20260924-353-linux-x64-compat-mode-adapter.md), [작업 354](../../../docs/design/20260924-354-linux-x64-pe-session.md)).

*This directory root is for Linux-specific code that is host-width-neutral or shared by x86 and x64. PE mapping (`native_pe_image`), import thunks, `NativePeSession`, fault observation, and `NativeInProcessRunner` are shared by both widths and live here, along with the import-handler contract (`native_import_gate.h`) and the guest-fault shape (`native_guest_fault.h`). The process bootstrap (`native_process_bootstrap.h`), import bridge (`native_import_bridge.h`), and below-4-GiB allocation (`native_low_memory.h`) are declared here and implemented per width. Facade module images and sets, dynamic thunks, and the kernel32 diagnostic are shared at the root too (Task 355). Guest SEH dispatch decisions (`native_guest_seh`), the instruction trace (`native_instruction_trace`), and the GetVersion diagnostic are shared by both widths too (Task 356). `x86/` holds direct i386 execution (the i386 helper was removed in Task 379). `x64/` holds the transition runtime (`native_compat_mode*`) that runs guests in CS `0x23` compatibility mode inside an x86-64 process, the bootstrap and bridge built on it, and synthetic probes ([Task 353](../../../docs/design/20260924-353-linux-x64-compat-mode-adapter.md), [Task 354](../../../docs/design/20260924-354-linux-x64-pe-session.md)).*
