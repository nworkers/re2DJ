# src/platform/linux

Linux x86·x64 product host backend와 별도 i386 production helper를 둡니다. `original_runner.cpp`는 두 제품 CLI를 `ExecutionBackend`에 연결합니다. `native_process_bootstrap.cpp`는 guard-page guest stack, 최소 TEB/PEB, FS selector와 signal fault context를 소유합니다. `native_ipc_host_probe.cpp`는 PE32 mapping·재배치·TLS·import gate event/reply, 제한된 stack memory IPC, pending import terminal stop과 구조화된 invalid-instruction fault를 합성 이미지로 검증합니다.

*This directory contains the Linux x86/x64 product-host backend and a separate i386 production helper. `original_runner.cpp` connects both product CLIs to `ExecutionBackend`. `native_process_bootstrap.cpp` owns the guarded guest stack, minimal TEB/PEB, FS selector, and signal-fault context. The Linux x86 product library also contains `native_in_process_runner.cpp`, selected only by explicit first-import and resolver diagnostic CLI options. `native_ipc_host_probe.cpp` validates PE32 mapping, relocation, TLS, import-gate event/reply, bounded stack-memory IPC, pending-import terminal stop, and a structured invalid-instruction fault with synthetic images.*

Linux POSIX 헤더는 이 플랫폼 디렉터리에서만 포함할 수 있습니다. 대소문자를 구분하는 파일 시스템 때문에 게스트 경로 해석은 `re2dj::hdd::HddRoot`를 반드시 거쳐야 합니다. synthetic native probe는 공용 `ImportDispatcher`로 import를 완료하고 `kStop`이 helper continuation 없이 terminal 상태가 되는지 확인합니다. 제품 경로에는 아직 실제 Win32 API binding이 없으므로 첫 미구현 import·process exit·guest signal fault에서 통제 정지합니다.

*Linux POSIX headers may only be included in this platform directory. Because the file system is case-sensitive, guest path resolution must always go through `re2dj::hdd::HddRoot`. The synthetic native probe completes imports through the shared `ImportDispatcher` and verifies that `kStop` becomes terminal without a helper continuation. The product path has no actual Win32 API bindings yet and therefore stops in a controlled way at its first unimplemented import, process exit, or guest-signal fault.*

작업 446부터 두 폭이 함께 쓰던 OS 중립 러너(PE mapping, import thunk, facade 모듈 이미지, 게스트 SEH 판단, 게스트 스레드, continuation, legacy I/O, 진단, 세 backend 계약)는 [`../native/`](../native/README.md)에 있습니다. 이 디렉터리에는 그 계약의 Linux 구현만 남습니다. 루트의 `native_host_services.cpp`는 메모리·시계 계약을 `mmap`·`clock_gettime`으로 구현하고, `native_host_protection.h`와 `native_signal_fault.h`는 `PROT_*`와 시그널 번호를 공용 값으로 바꿉니다. 자식 프로세스 런처와, 런처(#12)가 고른 게임을 자기 실행 파일의 새 프로세스로 실행하는 `self_process.cpp`도 루트에 있습니다. SDL host(창·입력·소리)는 작업 447부터 두 OS 공용인 [`../sdl/`](../sdl/README.md)에 있습니다. `x86/`에는 i386 직접 실행 구현이 있습니다(i386 helper는 작업 379에서 제거). `x64/`에는 x86-64 프로세스 안에서 CS `0x23` compatibility mode로 게스트를 실행하는 전환 runtime(`native_compat_mode*`), 그 위의 bootstrap·bridge 구현, 합성 probe가 있습니다([작업 353](../../../docs/design/20260924-353-linux-x64-compat-mode-adapter.md), [작업 354](../../../docs/design/20260924-354-linux-x64-pe-session.md)). x86·x64 파일은 `native` 계약을 구현하므로 namespace `re2dj::platform::native`를 씁니다.

*From task 446 the OS-neutral runner both widths shared (PE mapping, import thunks, facade module images, guest SEH decisions, guest threads, the continuation, legacy I/O, diagnostics and the three backend contracts) lives in [`../native/`](../native/README.md), and this directory keeps only their Linux implementations: `native_host_services.cpp` at the root serves the memory and clock contract through `mmap` and `clock_gettime`, and `native_host_protection.h` and `native_signal_fault.h` turn `PROT_*` flags and signal numbers into the shared values. The child launcher is at the root too, as is `self_process.cpp`, which runs the game the launcher (#12) chose as a new process of the program's own executable; the SDL hosts (window, input, sound) live in [`../sdl/`](../sdl/README.md), shared by both OSes, from task 447. `x86/` holds direct i386 execution (the i386 helper was removed in task 379); `x64/` holds the transition runtime (`native_compat_mode*`) that runs guests in CS `0x23` compatibility mode inside an x86-64 process, the bootstrap and bridge built on it, and synthetic probes ([task 353](../../../docs/design/20260924-353-linux-x64-compat-mode-adapter.md), [task 354](../../../docs/design/20260924-354-linux-x64-pe-session.md)). The x86 and x64 files implement the `native` contracts and so use namespace `re2dj::platform::native`.*
