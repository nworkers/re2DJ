# src/platform/windows

64비트 Windows 전용 backend가 들어갈 자리입니다. 아직 비어 있습니다.

*64-bit Windows backend. Empty for now.*

rePIU와 달리 호스트가 64비트이므로 디렉터리 이름에 비트 폭을 넣지 않습니다. 여기서만 `<windows.h>`를 포함할 수 있습니다.

*Unlike rePIU the host is 64-bit, so the directory name carries no bit width. This is the only place that may include `<windows.h>`.*
