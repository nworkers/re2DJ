# 작업 407 설계 — ShowWindow / Task 407 design — ShowWindow

선행: [작업 406 설계](20260927-406-crt-startup-kernel32.md)

## 배경 / Background

작업 406 뒤 Linux의 EZ2DJ 1st는 WinMain에서 `WS_POPUP` 창을 숨긴 채 만들고, `user32!ShowWindow(hwnd, SW_SHOW)`에서 멈췄다. 4th는 창을 `WS_VISIBLE`로 만들어서 이 함수를 쓰지 않았다.

*After Task 406, EZ2DJ 1st on Linux created its `WS_POPUP` window hidden in WinMain and stopped at `user32!ShowWindow(hwnd, SW_SHOW)`. 4th creates its window `WS_VISIBLE` and never calls this function.*

### 측정 / Measurements

Windows 11(WOW64)에서 1st와 같은 모양의 창(`WS_EX_APPWINDOW`, `WS_POPUP`)을 숨긴 채 만들어 측정했다.

*Measured on Windows 11 (WOW64) with a window of 1st's shape (`WS_EX_APPWINDOW`, `WS_POPUP`) created hidden.*

| 경우 / Case | 결과 / Result |
| --- | --- |
| 숨긴 창에 `SW_SHOW` / `SW_SHOW` on a hidden window | `WS_VISIBLE` 생성과 같은 메시지 순서: `WM_SHOWWINDOW`, `WM_WINDOWPOSCHANGING` 두 번, `WM_ACTIVATEAPP`, `WM_NCACTIVATE`, `WM_ACTIVATE`(안에서 `WM_SETFOCUS`), `WM_NCPAINT`, `WM_ERASEBKGND`, `WM_WINDOWPOSCHANGED`. IME·접근성 메시지는 이전 측정처럼 빼고 본다. 0을 돌려주고 last error 0 / *the same messages as a `WS_VISIBLE` creation, IME and accessibility messages aside; returns 0, last error 0* |
| 이미 보이는 창에 다시 / again on a visible window | 메시지 없음, 24, last error 그대로 / *no message, 24, last error unchanged* |
| 없는 창 / unknown window | 0, `ERROR_INVALID_WINDOW_HANDLE`(1400) |

## 결정 / Decisions

1. `CreateWindowExA`의 `WS_VISIBLE` 경로에 있던 표시·활성화 순서를 `ShowHiddenWindow`로 떼어 낸다. `ShowWindow(SW_SHOW)`도 같은 함수를 쓴다.
   *The show and activation sequence in `CreateWindowExA`'s `WS_VISIBLE` path moves into `ShowHiddenWindow`, which `ShowWindow(SW_SHOW)` also uses.*
2. 다른 창이 활성인 상태에서 창을 보이면 Windows는 그 창을 비활성화하는 메시지도 보낸다. 모델에는 그 부분이 없어서 멈춘다. `SW_SHOW` 말고 다른 명령도 멈춘다.
   *Showing a window while another is active, which Windows deactivates with messages of its own, stops; so does any command other than `SW_SHOW`.*
3. host 창은 전처럼 ddraw의 화면 모드 설정에서 띄운다.
   *The host window is still shown when ddraw sets the display mode.*
