# 작업 415 설계 — IDirect3D3::FindDevice를 공용 core로 / Task 415 design — IDirect3D3::FindDevice on a shared core

선행: [작업 414 설계](20260928-414-dx6-cooperative-level.md)

## 배경 / Background

작업 414 뒤 Linux의 EZ2DJ 1st는 `IDirect3D3::FindDevice`에서 멈췄다. Windows DX6 facade(`D3dFindDevice`)는 이 답을 facade 안에서 직접 만든다.

- 크기가 다른 검색·결과 구조체는 `DDERR_INVALIDPARAMS`다.
- 하드웨어가 아닌 장치를 찾으면(`D3DFDS_HARDWARE`에 `bHardware` FALSE) `DDERR_NOTFOUND`다.
- 그 밖에는 HAL 장치 GUID와 하드웨어 설명 네 가지(클리핑, 16비트 렌더·Z 깊이)를 주고 나머지는 0이다.

## 결정 / Decisions

1. 공용 core에 DirectX 6 구조체를 둔다: `D3dDeviceDesc6`(252바이트), `D3dFindDeviceSearch`(92), `D3dFindDeviceResult`(524). Windows 쪽 `directx_abi_windows.h`에서 SDK(`DIRECT3D_VERSION 0x0600`)와 크기·오프셋·상수를 `static_assert`로 맞춘다.
   *The shared core gains the DirectX 6 structures (`D3dDeviceDesc6`, 252 bytes; `D3dFindDeviceSearch`, 92; `D3dFindDeviceResult`, 524), checked against the SDK at `DIRECT3D_VERSION 0x0600` in the Windows `directx_abi_windows.h` for sizes, offsets, and constants.*
2. `directx::FindDevice`가 facade의 규칙을 그대로 담는다. Windows facade와 Linux `IDirect3D3::FindDevice`가 이를 쓴다. 결과는 `DD_OK`일 때만 채운다.
   *`directx::FindDevice` holds the facade's rules unchanged; the Windows facade and Linux `IDirect3D3::FindDevice` both use it, filling the result only on `DD_OK`.*
