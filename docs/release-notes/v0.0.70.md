# re2DJ v0.0.70

## 변경 사항

- 게임 중 OSD(백틱 키) 맨 위에 "Fullscreen"과 "Keep aspect ratio"가 생겼습니다. 비율 유지를 끄면 4:3 화면이 창이나 모니터 전체로 늘어납니다. 게임 창에서 Alt+Enter로도 전체 화면을 바꿀 수 있습니다.
- OSD·Alt+Enter·더블클릭으로 바꾼 전체 화면과 비율 유지는 `cfg/re2dj.ini`에 저장돼 다음 실행이 그대로 시작합니다. 명령줄의 `--fullscreen`/`--windowed`, 새 `--keep-aspect`/`--stretch`가 있으면 그것이 우선입니다.
- 런처 Options 맨 위에도 두 항목이 있고, 런처 창도 그 값을 따릅니다(전체 화면으로 열기, Alt+Enter, 비율 유지 시 가운데 배치). 목록에서 Space는 선택만 하고, Enter·패드 A·더블클릭이 게임을 시작합니다.
- EZ2DJ 게임패드 기본 배치가 바뀌었습니다: 1P 1~5번 키는 십자키 왼쪽·위·A·Y·B, 페달은 X, 이펙터 1~4는 LB·RB·LT·RT입니다. 시작·코인·턴테이블은 그대로입니다.
- EZ2DJ 3rd Trax가 실행됩니다. 3rd 덤프는 창 모드 DirectDraw를 써서 시작 직후 멈췄습니다.

## 검증

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Linux x64·x86에서 OSD·Alt+Enter·런처의 전체 화면과 비율 유지, 설정 저장과 다음 실행 반영을 화면으로 확인
- Linux에서 3rd를 곡 플레이까지 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.70

## Changes

- The in-game OSD (backtick) now starts with "Fullscreen" and "Keep aspect ratio"; with keep-aspect off the 4:3 picture stretches over the whole window or monitor. Alt+Enter in the game window switches fullscreen too.
- Fullscreen and keep-aspect changed through the OSD, Alt+Enter or a double click are kept in `cfg/re2dj.ini`, and the next run starts the same way; `--fullscreen`/`--windowed` and the new `--keep-aspect`/`--stretch` on the command line still win.
- The launcher's Options start with the same two items and its own window follows them (opening fullscreen, Alt+Enter, a centred layout when keeping the shape). On its list Space only selects; Enter, the pad's A or a double click starts the game.
- EZ2DJ's default gamepad layout changed: player 1's keys 1 to 5 are the d-pad's left and up, A, Y and B, the pedal X, and effectors 1 to 4 LB, RB, LT and RT; start, coin and the turntable are unchanged.
- EZ2DJ 3rd Trax now runs; its dump uses windowed DirectDraw and stopped right after start.

## Resolved issues

- [#14](https://github.com/reexec/re2DJ/issues/14) Fullscreen and keep-aspect options, kept in cfg, and launcher pad behaviour (rePIU #45, #34) — PR [#16](https://github.com/reexec/re2DJ/pull/16)
- [#15](https://github.com/reexec/re2DJ/issues/15) ez2dj3rd stops at user32 GetClientRect (windowed DirectDraw) — PR [#16](https://github.com/reexec/re2DJ/pull/16)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- Fullscreen and keep-aspect through the OSD, Alt+Enter and the launcher, and settings saved and followed by the next run, checked on screen on Linux x64 and x86
- 3rd played through a song on Linux

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
