# re2DJ v0.0.41

## 변경 사항

- EZ2DJ 4th Trax에서 게임 플레이 중 노트와 롱노트가 사라지던 렌더링 문제를 수정했습니다.
- 깊이 테스트를 사용하지 않는 원본 변환 정점의 비정상적인 깊이값이 OpenGL 클립 단계에서 노트를 제거하지 않도록 보정했습니다.
- 목적지 알파 블렌드 계수 지원을 추가하여 노트·마스크 레이어의 Direct3D draw가 사전 거부되지 않도록 했습니다.
- 640×480, 1280×960, 1920×1440 정수 배율 화면은 원본 픽셀 경계를 보존하고, 비정수 배율 화면은 선형 필터를 사용하도록 최종 화면 필터를 정리했습니다.
- `--graphics-draw-diagnostics` complete capture 모드에서 전체 그래픽·VFS 진단을 수집할 수 있도록 진단 로거를 보완했습니다.

## 검증

- Windows x86 Debug 빌드 성공
- Windows x86 단위 테스트 `1694 checks, 0 failures`
- Windows x86 결정적 CTest 4/4 통과
- EZ2DJ 4th Trax 실제 게임플레이에서 노트 및 롱노트 출력 확인

원본 게임 실행 파일, HDD 데이터, CHD는 배포 패키지에 포함되지 않습니다.

## English

# re2DJ v0.0.41

## Changes

- Fixed the EZ2DJ 4th Trax rendering issue that made notes and long notes disappear during gameplay.
- Corrected invalid depth values from original transformed vertices when depth testing is disabled, preventing OpenGL clipping from removing the notes.
- Added destination-alpha blend-factor support so Direct3D note and mask draws are not rejected before reaching the renderer.
- Preserved original pixel boundaries at 640×480, 1280×960, and 1920×1440 integer scales, while using linear filtering for non-integer final presentation scales.
- Completed the diagnostic logger so `--graphics-draw-diagnostics` can capture full graphics and VFS traces for investigations.

## Verification

- Windows x86 Debug build succeeded.
- Windows x86 unit tests: `1694 checks, 0 failures`.
- Four deterministic Windows x86 CTest cases passed.
- Notes and long notes were confirmed visible during real EZ2DJ 4th Trax gameplay.

The original game executable, HDD data, and CHD images are not included in the distribution package.
