# re2DJ v0.0.64

## 변경 사항

- 게임 화면에 CRT 모니터 느낌을 입히는 후처리 셰이더가 생겼습니다.
  - 내장 `crt`(휜 화면, 주사선, 마스크)와 `scanline`이 들어 있고, `shaders` 폴더에 `.glsl` 파일을 넣어 직접 만든 셰이더도 쓸 수 있습니다(libretro 단일 pass GLSL 형식).
  - `re2dj ez2dj4th --post-shader crt`처럼 고르거나, 환경 변수 `RE2DJ_POST_SHADER`로 정합니다. `--post-shader=crt` 형식도 됩니다.
  - 실행 중에는 백틱(`` ` ``) 키로 연 OSD의 Screen shader 메뉴에서 바꾸고 매개변수를 조절할 수 있습니다.
  - 화면에 보이는 단계에서만 적용되므로 게임 동작에는 영향이 없습니다. 기본값은 셰이더 없음(`none`)입니다.
- 명령행에서 `--`는 옵션의 끝을 뜻합니다. 뒤의 인자는 타깃 id로 읽습니다.
- README에 셰이더 비교 화면을 넣었고, 프로젝트 사이트에 개발 기록 두 편(후처리 셰이더, Win32 직접 로딩 전환)을 올렸습니다.
- CI의 Linux clang 빌드 실패를 고쳤습니다.

## 검증

- Windows x86, Linux x64(clang·gcc)·x86 빌드와 테스트 통과
- 새 OpenGL 셰이더 검사가 Windows와 WSL에서 모두 통과
- Windows에서 4th·6th, Linux에서 4th를 셰이더와 함께 실행

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.64

## Changes

- Post-processing shaders now put a CRT monitor look on the game's picture.
  - The built-in `crt` (a curved screen, scanlines, a mask) and `scanline` ship inside, and your own shaders work too as `.glsl` files in the `shaders` folder (libretro single-pass GLSL).
  - Choose one with `re2dj ez2dj4th --post-shader crt` (or `--post-shader=crt`), or with the `RE2DJ_POST_SHADER` environment variable.
  - While running, the Screen shader menu in the OSD (the backtick key) switches shaders and adjusts their parameters.
  - Shaders apply only to what is shown, so the game behaves the same; the default is no shader (`none`).
- On the command line, `--` ends the options; what follows is read as the target id.
- The README shows shader comparison screens, and the project site gains two dev-log posts (post-processing shaders, and the move of Win32 to direct loading).
- Fixed the Linux clang build failing in CI.

## Validation

- The Windows x86 and Linux x64 (clang, gcc) and x86 builds and tests pass
- The new OpenGL shader check passes on Windows and WSL
- 4th and 6th ran with shaders on Windows, and 4th on Linux
- Switching shaders with the mouse in the OSD has not been checked yet.

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
