# re2DJ v0.0.72

## 변경 사항

- 패드로 게임과 런처를 끝낼 수 있습니다. 한 패드에서 LT + RT + 왼쪽 스틱 클릭 + 오른쪽 스틱 클릭을 1초 동안 함께 누르고 있으면, 게임은 끝나 런처로 돌아오고 런처는 닫힙니다. 키보드도 창 닫기 버튼도 없는 스팀덱 게임 모드용이며, 그동안에도 각 버튼은 게임에 그대로 들어갑니다.
- 빌드 환경 정리: GitHub Actions의 Node.js 20 경고를 없애고 Linux 빌드 서버를 Ubuntu 26.04로 고정했습니다. Linux 릴리스 파일은 이전과 같은 Debian 12 환경에서 만들어지므로, 스팀덱에서 필요한 시스템 라이브러리(glibc 2.36 이상)는 그대로입니다.

## 해결된 이슈

- [#19](https://github.com/reexec/re2DJ/issues/19) GitHub Actions의 Node.js 20 경고와 Ubuntu 26 runner — PR [#21](https://github.com/reexec/re2DJ/pull/21)
- [#20](https://github.com/reexec/re2DJ/issues/20) 패드 조합 LT+RT+L3+R3으로 게임 종료(스팀덱) — PR [#21](https://github.com/reexec/re2DJ/pull/21)

## 검증

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과, 경고 없음
- 새 빌드 서버에서 만든 Linux x64 실행 파일이 v0.0.71과 바이트 단위로 같음을 확인
- Linux에서 Xbox 패드로 게임·런처 종료 조합을 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.72

## Changes

- The pad can end the game and the launcher: holding LT + RT + left stick click + right stick click together on one pad for a second ends the game back to the launcher and closes the launcher. It is for Steam Deck game mode, which has neither keyboard nor close button, and each control still reaches the game meanwhile.
- Build housekeeping: GitHub Actions' Node.js 20 warnings are gone and the Linux build servers are pinned to Ubuntu 26.04. The Linux release files are still made in the same Debian 12 environment, so the system library a Steam Deck needs (glibc 2.36 or later) is unchanged.

## Resolved issues

- [#19](https://github.com/reexec/re2DJ/issues/19) GitHub Actions Node.js 20 warnings and Ubuntu 26 runners — PR [#21](https://github.com/reexec/re2DJ/pull/21)
- [#20](https://github.com/reexec/re2DJ/issues/20) End the game with the pad combination LT+RT+L3+R3 (Steam Deck) — PR [#21](https://github.com/reexec/re2DJ/pull/21)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions with no warning
- The Linux x64 executable from the new build servers is byte-identical to v0.0.71's
- The game and launcher exit chord checked on Linux with an Xbox pad

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
