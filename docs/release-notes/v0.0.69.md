# re2DJ v0.0.69

## 변경 사항

- `re2dj`를 인자 없이 실행하면(탐색기에서 더블클릭 포함) 런처 창이 뜹니다. 내장 프로필 8개마다 `roms/` 아래에서 실행할 수 있는지와 그 이유를 보여 주고, 고른 게임을 실행합니다. 게임이 끝나면 런처로 돌아옵니다.
- 런처에서 전체 화면, 색 깊이(16/32비트), 화면 셰이더, 소리 크기를 고를 수 있습니다. 바꾼 값과 마지막 프로필은 `cfg/re2dj.ini`에 남아 다음 실행에도 적용됩니다.
- 키보드·마우스·게임패드로 조작합니다. Enter나 더블클릭으로 시작하고 Esc로 종료합니다.
- 인자를 준 실행은 지금과 같습니다. 인자 없이 사용법만 보려면 `RE2DJ_LAUNCHER=0`을 줍니다. 창을 열 수 없는 환경에서도 사용법을 출력합니다.

## 검증

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Linux x64·x86에서 런처를 직접 조작해 6th 실행과 런처 복귀, 옵션 적용과 저장을 확인
- Windows에서의 실제 실행은 아직 확인 전입니다

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.69

## Changes

- Running `re2dj` without arguments, double-clicking it included, opens a launcher window. It shows, for each of the eight built-in profiles, whether it can run from `roms/` and why not, starts the chosen game, and comes back when the game ends.
- The launcher chooses fullscreen, colour depth (16 or 32 bits), screen shader and sound gain; changed values and the last profile are kept in `cfg/re2dj.ini` for the next run.
- Keyboard, mouse and gamepads drive it: Enter or a double click starts, Esc quits.
- Runs with arguments are unchanged. `RE2DJ_LAUNCHER=0` prints the usage instead, as does a run that cannot open a window.

## Resolved issues

- [#12](https://github.com/reexec/re2DJ/issues/12) A launcher shown when run without arguments — PR [#13](https://github.com/reexec/re2DJ/pull/13)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- The launcher driven by hand on Linux x64 and x86: running 6th and returning, and options applied and saved
- A real run on Windows is still to be checked

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
