# re2DJ v0.0.60

## 변경 사항

- **Linux 릴리스 패키지를 배포합니다.** 릴리스마다 Windows x86 zip과 함께 Linux x86-64·x86 tar.gz를 올립니다.
  - Debian 12 컨테이너에서 빌드하며, libstdc++를 정적으로 링크합니다. glibc 2.36 이상(Debian 12, Ubuntu 23.04 이후)에서 실행됩니다.
  - 압축을 푼 디렉터리에서 `./re2dj <세트>`로 실행합니다. 예: `./re2dj ez2dj4th`. 자산은 `roms/<세트>`에 둡니다.
  - X11 또는 Wayland와 OpenGL, 그리고 PipeWire·PulseAudio·ALSA 중 하나가 필요합니다. x86 패키지는 32비트 x86 Linux용입니다.
  - Release workflow가 세 플랫폼을 각각 빌드·테스트한 뒤, 모두 성공해야 release를 게시합니다. Windows Release 빌드가 runner에 없는 생성기를 요구하던 문제를 고쳐, 처음으로 workflow 전체가 통과했습니다.
- **EZ2DJ 6th의 Remember 1st가 Linux에서 처음부터 끝까지 동작합니다.**
  - 모드 선택에서 Remember 1st를 고르면 launcher가 동봉된 1st Tracks를 실행합니다. 6th에서 넣은 크레딧이 1st로 넘어갑니다.
  - 1st에서 게임 한 판을 마치면 6th로 돌아옵니다.
  - Windows 제품도 launcher가 두 번째 자식을 따라가도록 바꿨습니다.
- **6th에서 Autoplay를 쓸 수 있습니다.** 곡 선택 화면에서 OSD(백틱)의 Autoplay를 켜면 곡이 자동으로 연주됩니다.
  - Linux OSD에도 Autoplay 토글이 생겼습니다. 3rd·4th·5th·1st SE·EZ2Dancer 2nd MOVE도 Linux에서 쓸 수 있습니다.
  - 토글은 실행 중인 실행 파일의 빌드에만 나타납니다. Remember 1st(동봉 1st)에는 켜고 끌 autoplay 변수가 없어 나타나지 않습니다.
- **Wayland 세션에서 Linux 창이 열립니다.** 창을 가운데로 옮기는 요청을 Wayland가 거절해도 실행이 멈추지 않습니다.
- **EZ2DJ 턴테이블 `step` 기본값이 2입니다.** `config/ez2dj-io.example.ini`와 같습니다.
- 그 밖에
  - Linux 게스트 파일의 overlay 경로가 Windows처럼 대소문자를 구분하지 않습니다.
  - 게스트가 지운 원본 이미지 파일은 원본을 바꾸지 않고 overlay에 "지움"으로 표시합니다.
  - 게스트 스레드를 남긴 Linux 실행이 끝날 때 나던 충돌을 고쳤습니다.
  - 프로젝트 사이트(<https://nworkers.github.io/re2DJ/>)와 `CREDITS.md`를 추가했습니다. 다운로드 페이지는 플랫폼별 패키지를 보여 줍니다.
  - 릴리스 패키지에 `THIRD_PARTY_NOTICES.md`와 `CREDITS.md`가 들어갑니다.

## 검증

- Release workflow(`workflow_dispatch`)에서 Windows x86, Linux x86-64, Linux x86의 Release 빌드·테스트·패키징 통과
- 단위 테스트 5,934건 전체 통과(Linux x64)
- Linux x64·x86 패키지가 C 런타임만 링크하고 glibc 2.36 이하만 요구함을 확인. CI가 만든 두 패키지로 6th 실행 확인
- Linux에서 6th → Remember 1st → 게임 한 판 → 6th 복귀, 6th Autoplay 동작을 사용자가 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.60

## Changes

- **Linux release packages.** Each release ships Linux x86-64 and x86 tar.gz files alongside the Windows x86 zip.
  - They are built in Debian 12 containers with libstdc++ linked statically, and run on glibc 2.36 or later (Debian 12, Ubuntu 23.04 onward).
  - Run `./re2dj <set>` from the extracted directory, e.g. `./re2dj ez2dj4th`, with the assets under `roms/<set>`.
  - They need X11 or Wayland with OpenGL, and PipeWire, PulseAudio or ALSA; the x86 package is for 32-bit x86 Linux.
  - The Release workflow builds and tests each platform and publishes only when all succeed. The Windows Release build no longer asks for a generator the runner lacks, and the whole workflow passed for the first time.
- **EZ2DJ 6th's Remember 1st works end to end on Linux.**
  - Choosing Remember 1st in mode select makes the launcher run the bundled 1st Tracks, carrying over the credits put in on 6th.
  - Finishing one game in 1st returns to 6th.
  - The Windows product's launcher now follows the second child too.
- **Autoplay in 6th.** Ticking Autoplay in the OSD (backtick) at song select plays the song by itself.
  - The Linux OSD gains the Autoplay toggle, so 3rd, 4th, 5th, 1st SE and EZ2Dancer 2nd MOVE have it on Linux too.
  - The toggle appears only for the build that is running; Remember 1st (the bundled 1st) has no switchable autoplay variable and shows none.
- **The Linux window opens on Wayland sessions**: Wayland refusing to centre the window no longer stops the run.
- **The EZ2DJ turntable `step` defaults to 2**, matching `config/ez2dj-io.example.ini`.
- Also
  - Linux guest-file overlay paths ignore case, as on Windows.
  - An original image file the guest deletes is marked deleted in the overlay, leaving the original untouched.
  - A Linux run that left a guest thread behind no longer crashes as it ends.
  - The project site (<https://nworkers.github.io/re2DJ/>) and `CREDITS.md` were added; the download page lists per-platform packages.
  - Release packages carry `THIRD_PARTY_NOTICES.md` and `CREDITS.md`.

## Validation

- The Release workflow (`workflow_dispatch`) passed the Release build, tests and packaging for Windows x86, Linux x86-64 and Linux x86
- All 5,934 unit checks pass (Linux x64)
- The Linux x64 and x86 packages link only the C runtime and need glibc 2.36 at most; both CI-built packages ran 6th
- The user confirmed on Linux 6th → Remember 1st → one game → back to 6th, and 6th's Autoplay

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
