# re2DJ v0.0.63

## 변경 사항

- Windows에서도 Linux와 같은 방식으로 원본 실행 파일을 re2dj 자기 프로세스 안에서 실행합니다.
  - 원본을 별도 Windows 프로세스로 띄우고 DLL을 주입하던 방식은 지웠습니다. Windows 패키지에는 `re2dj.exe` 하나만 들어갑니다.
  - 창·소리·키보드는 Linux와 같은 SDL3 경로를 씁니다.
  - 시작할 때 re2dj가 자신을 한 번 더 띄웁니다. 원본이 놓여야 할 메모리 주소를 먼저 확보하기 위해서입니다.
- 다음 옵션은 없어졌으며, 쓰면 알 수 없는 옵션으로 거부됩니다: `--demo-volume`, `--audio-volume-trace`, `--guest-wait-trace`, `--vsync`.
- 이전 Windows 패키지는 Windows Defender가 악성으로 판정해 격리하는 경우가 있었습니다. 주입 방식이 없어져 그 원인으로 보이는 동작이 사라졌습니다.
- README와 프로젝트 사이트 소개에 1st SE, 4th, 5th, 6th, EZ2Dancer 2nd MOVE의 스크린샷을 넣었습니다.

## 성능

- 기본 설정(vsync on)에서는 다섯 타깃 모두 이전과 같이 60fps를 유지합니다. CPU 사용은 코어 하나 기준 2~4%p 늘었습니다.
- vsync를 끈 최대 처리량은 이전보다 4th −17%, 1st SE −22%, 5th −11%, 6th −16% 낮고, 2nd MOVE는 +10% 높습니다. 화면 주기보다 7~20배 빨라 실제 플레이에는 영향이 없습니다. 원인 분석과 개선은 다음 작업으로 남겼습니다.
- 메모리(private bytes)는 이전보다 많이 잡힙니다(최대 약 1.4 GB).

## 검증

- Windows x86 빌드와 테스트, Linux x64·x86 빌드와 테스트 통과
- Windows에서 4th, 1st SE, 5th, 6th, EZ2Dancer 2nd MOVE 실행과 성능 측정
- Windows 게임패드 실제 입력, 전체 화면, OSD 조작은 아직 확인하지 않았습니다.

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.63

## Changes

- Windows now runs the original executable inside re2dj's own process, the same way as Linux.
  - The old way, starting the original as its own Windows process and injecting a DLL, is gone; the Windows package holds only `re2dj.exe`.
  - The window, sound and keyboard use the same SDL3 path as Linux.
  - At start re2dj launches itself once more, to secure the memory address the original must sit at first.
- These options are gone and are now refused as unknown: `--demo-volume`, `--audio-volume-trace`, `--guest-wait-trace`, `--vsync`.
- Earlier Windows packages were sometimes quarantined by Windows Defender as malicious. With injection gone, the behaviour that likely caused it is gone too.
- The README and the project site's introduction show screenshots of 1st SE, 4th, 5th, 6th and EZ2Dancer 2nd MOVE.

## Performance

- At the default (vsync on) all five targets hold 60 fps as before; CPU use rises by 2 to 4 points of one core.
- Peak throughput with vsync off is lower than before by 17% for 4th, 22% for 1st SE, 11% for 5th and 16% for 6th, and 10% higher for 2nd MOVE. It is still 7 to 20 times the display rate, so play is unaffected; finding the cause and improving it is left for later work.
- Memory (private bytes) is higher than before, up to about 1.4 GB.

## Validation

- The Windows x86 build and tests, and the Linux x64 and x86 builds and tests, pass
- 4th, 1st SE, 5th, 6th and EZ2Dancer 2nd MOVE run on Windows, with performance measured
- Real gamepad input, fullscreen and the OSD on Windows are not checked yet.

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
