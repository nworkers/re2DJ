# re2DJ v0.0.42

## 변경 사항

- EZ2Dancer `ez2d2m`의 coin 입력 설정과 coin counter 처리를 보완했습니다.
- `jam.ezw`가 CHD/FAT32 VFS에서 정상적으로 열리고 읽히는지 확인할 수 있도록 EZW·오디오 경계 진단을 확장했습니다.
- DirectSound streaming buffer를 append-only SDL FIFO가 아닌 synchronized shadow ring 기반 pull 방식으로 처리하도록 수정했습니다.
- 동일한 PCM 구간을 반복해서 Unlock하는 경우에도 재생 시간이 계속 진행되도록 했습니다.
- streaming buffer의 오래된 ring 구간이 1~2초마다 반복 재생되는 문제를 수정했습니다.
- Stop/restart 및 반복 Play 시 mixer track과 재생 cursor 상태를 보존·재생성하는 동작을 정리했습니다.
- 여러 곡이 같은 streaming buffer를 재사용할 때 후속 곡의 진단 로그가 누락되지 않도록 sampling 상태를 재설정했습니다.

## 검증

- Windows x86 Debug 전체 빌드 성공
- `re2dj_audio_stream_progress_test` 통과
- `re2dj_ez2dancer_keyboard_input_test` 통과
- `re2dj_windows_product_loader_probe` 통과
- `re2dj_unit_tests` 통과
- 실제 `ez2d2m`에서 JAM 음악 재생 정상 동작을 확인했습니다.

원본 게임 실행 파일, HDD 데이터, CHD 이미지는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.42

## Changes

- Improved the EZ2Dancer `ez2d2m` coin input configuration and coin-counter handling.
- Expanded EZW and audio-boundary diagnostics to verify that `jam.ezw` opens and reads correctly through the CHD/FAT32 VFS.
- Changed DirectSound streaming buffers from an append-only SDL FIFO approximation to a pull-based synchronized shadow ring.
- Streaming playback now continues through Unlock calls that contain identical PCM data.
- Fixed stale ring regions being replayed every one to two seconds.
- Clarified mixer-track recreation and playback-cursor handling across Stop/restart and repeated Play calls.
- Reset streaming diagnostic sampling state when multiple songs reuse the same buffer, so later-song traces are retained.

## Verification

- Full Windows x86 Debug build succeeded.
- `re2dj_audio_stream_progress_test` passed.
- `re2dj_ez2dancer_keyboard_input_test` passed.
- `re2dj_windows_product_loader_probe` passed.
- `re2dj_unit_tests` passed.
- Real `ez2d2m` JAM playback was confirmed working.

The original game executable, HDD data, and CHD images are not included in the distribution package.
