# re2DJ v0.0.66

## 변경 사항

- 릴리스 노트에 그 버전이 해결한 GitHub 이슈와 커밋 ID가 보입니다. GitHub Release 아래쪽에 커밋·이슈·PR 표가 자동으로 붙습니다.
- 같은 PC에서 Windows와 Linux x86·x64의 성능을 비교해 문서로 정리했습니다. 기본 설정에서는 모두 60 fps이고, Linux x64가 CPU를 가장 적게 씁니다.
- NVIDIA 그래픽 드라이버에서 Linux 32비트(x86) 버전을 쓸 때는 `SDL_VIDEO_DRIVER=x11`로 실행하는 편이 더 빠릅니다(Linux 빌드 가이드).

## 해결된 이슈

- [#3](https://github.com/nworkers/re2DJ/issues/3) 릴리스 노트에 해결된 이슈와 커밋 ID 표시 — PR [#5](https://github.com/nworkers/re2DJ/pull/5)
- [#4](https://github.com/nworkers/re2DJ/issues/4) Windows와 Linux x86·x64 성능 비교 — PR [#5](https://github.com/nworkers/re2DJ/pull/5)

## 검증

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Linux x86·x64에서 다섯 타깃을 vsync on/off로 두 번씩 실행해 성능 측정

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.66

## Changes

- Release notes show the GitHub issues and commit IDs a version resolves; a commit, issue and PR table is appended to the bottom of the GitHub Release automatically.
- The performance of Windows and Linux x86 and x64 on one PC is compared in a document: all hold 60 fps at the default, and Linux x64 uses the least CPU.
- With the NVIDIA graphics driver, the Linux 32-bit (x86) build runs faster with `SDL_VIDEO_DRIVER=x11` (see the Linux build guide).

## Resolved issues

- [#3](https://github.com/nworkers/re2DJ/issues/3) Show resolved issues and commit IDs in release notes — PR [#5](https://github.com/nworkers/re2DJ/pull/5)
- [#4](https://github.com/nworkers/re2DJ/issues/4) Compare Windows with Linux x86 and x64 performance — PR [#5](https://github.com/nworkers/re2DJ/pull/5)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- Performance measured on Linux x86 and x64, five targets with vsync on and off, twice each

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
