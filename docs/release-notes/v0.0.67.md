# re2DJ v0.0.67

## 변경 사항

- 백틱(`` ` ``)으로 여는 OSD의 프로세스 정보 아래에 Renderer 절이 생겼습니다. 화면을 그리는 GPU(OpenGL renderer), 제조사, OpenGL 버전, 비디오 드라이버(`windows`, `x11`, `wayland`)가 보입니다.
- llvmpipe나 GDI Generic 같은 소프트웨어 렌더러로 실행되면 붉은 글씨와 "Software rendering: no 3D acceleration" 문구로 알려 줍니다. 3D 가속 없이 느리게 도는 이유를 바로 알 수 있습니다.
- 같은 정보가 실행 로그에 `presentation: GL renderer: …` 한 줄로 남습니다.

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Windows에서 6th를 실행해 OSD의 Renderer 절과 로그 줄 확인, WSL에서 Linux x64 빌드와 단위 테스트 통과

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.67

## Changes

- The OSD opened with backtick (`` ` ``) gains a Renderer section below the process information: the GPU drawing the picture (the OpenGL renderer), its vendor, the OpenGL version and the video driver (`windows`, `x11`, `wayland`).
- A run on a software renderer such as llvmpipe or GDI Generic is flagged in red with "Software rendering: no 3D acceleration", so a slow run without 3D acceleration says why on the spot.
- The same information is written to the run log as one `presentation: GL renderer: …` line.

## Resolved issues

- [#6](https://github.com/nworkers/re2DJ/issues/6) Show the OpenGL renderer in the OSD — PR [#7](https://github.com/nworkers/re2DJ/pull/7)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- 6th run on Windows with the OSD's Renderer section and the log line checked; Linux x64 built and unit-tested on WSL

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
