# re2DJ v0.0.40

## 변경 사항

- Windows x86 Release 빌드와 배포 패키지 생성을 GitHub Actions로 자동화했습니다.
- `v*` 태그를 push하면 GitHub Release가 자동으로 생성되거나 갱신됩니다.
- Release 패키지에 실행 파일, 런타임 DLL, 설정 예시, 라이선스, 버전 정보와 릴리즈 노트를 포함합니다.
- 배포 ZIP의 SHA-256 체크섬 파일을 함께 생성합니다.
- `workflow_dispatch`로 Release를 게시하지 않고 검증용 workflow artifact만 생성할 수 있습니다.
- 원본 HDD, CHD, 게임 실행 파일 및 게임 데이터는 패키지에 포함하지 않습니다.

## 검증

- Windows x86 Release 빌드 성공
- Release CTest 통과
- VFS 열거 프로브 통과
- 배포 ZIP 및 SHA-256 체크섬 생성 확인

## English

# re2DJ v0.0.40

## Changes

- Automated the Windows x86 Release build and distribution packaging with GitHub Actions.
- Pushing a `v*` tag now creates or updates the corresponding GitHub Release automatically.
- Release packages include the executable, runtime DLL, configuration examples, license, version metadata, and release notes.
- Generated a SHA-256 checksum file next to the distribution ZIP.
- Added `workflow_dispatch` support for producing a verification artifact without publishing a Release.
- Original HDDs, CHDs, game executables, and game data are not included in the package.

## Verification

- Windows x86 Release build succeeded.
- Release CTest passed.
- VFS enumeration probe passed.
- Distribution ZIP and SHA-256 checksum generation verified.
