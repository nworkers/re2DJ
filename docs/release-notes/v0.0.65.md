# re2DJ v0.0.65

## 변경 사항

- 최신 배포판(Ubuntu 26.04, GCC 15)에서 빌드한 Linux x86(32비트) 버전이 실행 중 멈추던 문제를 고쳤습니다.
- 최신 clang(20 이상)으로도 빌드됩니다. 로그 라이브러리 spdlog를 1.15.3으로 올렸습니다.
- NVIDIA 그래픽 드라이버에서 32비트 버전을 Wayland 화면으로 띄우지 못하는 경우의 우회 방법을 Linux 빌드 가이드에 적었습니다.
- 데스크톱 Linux에서 셰이더, 6th 실행, 게임패드 연결과 코인 입력을 확인했습니다.

## 알아 둘 점

- 게임 창이 다른 창에 가려지거나 최소화되면 Linux 데스크톱(GNOME)이 화면 갱신을 줄여 게임이 느려집니다. 플레이할 때는 창을 보이게 두세요.

## English

# re2DJ v0.0.65

## Changes

- Fixed the Linux x86 (32-bit) build from newer distributions (Ubuntu 26.04, GCC 15) stopping while running.
- Newer clang (20 and later) builds it too; the spdlog logging library moves to 1.15.3.
- The Linux build guide gives a workaround for when the NVIDIA driver cannot open the 32-bit build's window on Wayland.
- Shaders, running 6th, gamepad hot-plug and coin input were checked on desktop Linux.

## Good to know

- When the game window is covered or minimised, the Linux desktop (GNOME) slows its screen updates and the game slows down with it; keep the window visible while playing.

## Resolved issues

- [#1](https://github.com/nworkers/re2DJ/issues/1) Branch-push CI and an issue- and PR-based task workflow — PR [#2](https://github.com/nworkers/re2DJ/pull/2), commit [`26a9151`](https://github.com/nworkers/re2DJ/commit/26a9151d57726f898d58bfd34aeb7bf663a4daf0)
- Tasks 458, 459 and 460 began before issues and have no issue numbers; they are in the same commit.

## Validation

- Linux x64 and x86 builds (GCC 15, clang 21) and tests pass
- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- 4th and 6th ran on Linux x64 and x86

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
