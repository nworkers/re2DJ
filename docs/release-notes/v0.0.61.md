# re2DJ v0.0.61

## 변경 사항

- Linux에서 EZ2DJ 6th의 Remember 1st를 마치고 6th로 돌아올 때 re2dj가 끝나 버릴 수 있던 문제를 고쳤습니다.
  - launcher는 자식(6th, 1st)마다 re2dj를 다시 실행합니다. 실행하는 동안 re2dj 실행 파일이 새로 빌드되거나 교체되면, 다음 자식을 띄우지 못하고 멈췄습니다.
  - 이제 파일 경로가 아니라 지금 실행 중인 실행 파일 자체를 다시 실행합니다. 파일이 교체돼도 자식이 뜨고, 부모와 자식은 늘 같은 빌드로 돕니다.

## 검증

- 실행 파일을 지운 상태에서 launcher가 6th 자식을 띄우는 재현 시험 통과
- Linux x64 빌드(경고를 오류로)와 CTest 통과
- Linux에서 6th → Remember 1st → 게임 한 판 → 6th 복귀를 사용자가 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.61

## Changes

- Fixed re2dj sometimes ending on Linux when returning to EZ2DJ 6th after Remember 1st.
  - The launcher runs re2dj again for each child (6th, 1st). If the re2dj executable was rebuilt or replaced meanwhile, the next child could not start and the run stopped.
  - It now runs the executable that is running rather than its file path, so a replaced file no longer matters, and parent and child always run the same build.

## Validation

- A reproduction with the executable deleted now starts the 6th child
- The Linux x64 build (warnings as errors) and CTest pass
- The user confirmed 6th → Remember 1st → one game → back to 6th on Linux

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
