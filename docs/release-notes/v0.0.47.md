# re2DJ v0.0.47

## 변경 사항

- Dear ImGui 기반의 가벼운 On-Screen Display(OSD)를 추가했습니다.
  - 실행 중 백틱(`` ` ``) 키로 표시를 켜고 끌 수 있습니다.
  - OSD가 숨겨져 있을 때는 ImGui 프레임을 생성하지 않아 렌더링 오버헤드가 없습니다.
  - 화면 상단에 버전, 빌드 일시, 타깃 프로파일, 실행 파일 이름을 표시합니다.
  - 3rd에서 커서가 숨겨지는 동작을 보완하여 OSD 조작 시 마우스 커서가 유지되도록 했습니다.
- EZ2DJ 3rd Trax의 자율 연주(Autoplay) 토글을 지원합니다.
  - 복호화 덤프 분석을 통해 데모 오버레이나 음소거 등 부작용이 없는 내부 autoplay 플래그 주소를 특정했습니다.
  - 타깃 프로파일에 `GameControls`를 추가하고, 런처가 실행 파일의 빌드 timestamp(`0x3bca98a3`)가 일치할 때만 주입 런타임에 주소를 전달하여 안전하게 무장합니다.
  - 곡 시작 전에 OSD에서 Autoplay를 체크하면 해당 곡이 자동으로 연주됩니다.

## 검증

- Windows x86 Debug 및 Release 전체 빌드 성공
- 단위 테스트 1,804건 전체 통과 (`checks: 1804, failures: 0`)
- CTest 테스트 스위트 통과
- EZ2DJ 3rd Trax 실행 시 백틱 토글, 마우스 조작, 곡 선택 후 자율 연주 동작 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.47

## Changes

- Added a lightweight Dear ImGui on-screen display (OSD).
  - Toggled visible/hidden during runtime with the backtick (`` ` ``) key.
  - Builds no ImGui frame while hidden, avoiding rendering overhead.
  - Displays version, build timestamp, target profile, and executable name across the top of the window.
  - Restores the mouse cursor on hover to allow interaction despite 3rd hiding the cursor.
- Supported an Autoplay toggle for EZ2DJ 3rd Trax.
  - Located the internal autoplay flag address through decrypted image analysis, free from demo-play side effects like overlays or audio muting.
  - Introduced `GameControls` to target profiles; the launcher passes the flag address to the injected runtime only when the executable build timestamp (`0x3bca98a3`) matches.
  - Checking Autoplay in the OSD before starting a song plays the song automatically.

## Verification

- Full Windows x86 Debug and Release builds succeeded.
- All 1,804 unit test checks passed (`checks: 1804, failures: 0`).
- CTest test suite passed.
- Verified backtick toggling, mouse interaction, and autonomous song playback in EZ2DJ 3rd Trax.

The original game executable, HDD data, and CHD images are not included in the distribution package.
