# re2DJ v0.0.73

## 변경 사항

- 패드로 OSD를 열고 조작할 수 있습니다. 게임 중 한 패드에서 LT + RT + Y를 누르면 OSD가 열리고, 다시 누르면 닫힙니다. 키보드 없는 스팀덱 게임 모드에서도 화면 셰이더, 전체 화면, 비율 유지 같은 설정을 바꿀 수 있습니다.
- OSD가 열려 있는 동안 D-pad(또는 왼쪽 스틱)로 항목을 옮기고 A로 고르며, B로 열린 메뉴를 닫고 메뉴가 없으면 OSD를 닫습니다. 이 동안 패드 입력은 게임에 들어가지 않고, 닫을 때 누르고 있던 버튼도 손을 뗄 때까지 게임에 들어가지 않습니다.
- 키보드 백틱(`` ` ``)으로 여는 것도 그대로 되고, 키보드 입력은 OSD가 열려 있어도 게임에 들어갑니다.
- EZ2DJ 기본 배치에서는 LT·RT가 이펙터, Y가 4번 건반이라, 조합을 누르는 순간까지는 그 입력이 게임에도 들어갑니다.

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Linux에서 Xbox 패드로 OSD 열고 닫기, 항목 조작, B로 닫기, 그동안 게임에 패드 입력이 들어가지 않음을 확인

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.73

## Changes

- The pad can open and drive the OSD: in game, LT + RT + Y on one pad opens it and pressed again closes it, so the screen shader, fullscreen, keep-aspect and other settings can be changed in Steam Deck game mode without a keyboard.
- While it is open, the d-pad (or the left stick) moves between items and A chooses; B closes an open menu or, with none open, the OSD. Pad input never reaches the game meanwhile, and a button held as it closes stays out of the game until released.
- Backtick (`` ` ``) still opens it, and keyboard input still reaches the game with the OSD open.
- In EZ2DJ's default layout LT and RT are effectors and Y key 4, so they reach the game until the chord is complete.

## Resolved issues

- [#22](https://github.com/reexec/re2DJ/issues/22) Open and drive the OSD with a gamepad, LT+RT+Y (rePIU #55) — PR [#23](https://github.com/reexec/re2DJ/pull/23)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- On Linux with an Xbox pad: opening and closing the OSD, changing items, closing with B, and no pad input reaching the game meanwhile

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
