# re2DJ v0.0.71

## 변경 사항

- 런처가 새 버전을 알려 줍니다. 인자 없이 실행한 런처가 열리면 GitHub의 최신 릴리스를 확인하고, 더 새 버전이 있으면 맨 위에 알림과 **Update** 버튼이 나옵니다. 누르면 이 빌드에 맞는 파일을 받아 검증하고, 프로그램 파일만 바꾼 뒤 다시 시작합니다. `roms/`와 `cfg/`는 그대로입니다.
- 스팀덱에서는 같은 프로세스가 새 버전으로 바뀌므로, 게임 모드에서도 Steam이 실행이 끝났다고 보지 않습니다.
- 릴리스 압축 파일을 푼 폴더에서만 Update 버튼이 나옵니다. 끄려면 `cfg/re2dj.ini`의 `[Launcher]`에 `check_updates = 0`을 적습니다.
- 릴리스 파일 이름이 `re2DJ-v<버전>-<플랫폼>`으로 바뀌었습니다. 압축 안의 실행 파일은 `re2dj`(`re2dj.exe`) 그대로입니다.
- 스팀덱 설치와 업데이트 방법: [런처 업데이트 가이드](../guides/launcher-update.md)

## 해결된 이슈

- [#17](https://github.com/reexec/re2DJ/issues/17) 런처 자동 업데이트와 산출물 이름 re2DJ-v* (rePIU #48) — PR [#18](https://github.com/reexec/re2DJ/pull/18)

## 검증

- GitHub Actions에서 Windows x86, Linux x64(gcc·clang), Linux x86 빌드와 테스트 통과
- Linux에서 v0.0.70 릴리스로 실제 업데이트(받기, 검증, 교체, 같은 프로세스로 다시 시작)를 확인
- Windows에서의 실제 교체는 아직 확인 전입니다

원본 게임 실행 파일, HDD 데이터, CHD 이미지, Hardlock 자료(`cfg/`)는 배포 패키지에 포함하지 않습니다.

## English

# re2DJ v0.0.71

## Changes

- The launcher tells of a new version: when it opens (re2dj run without arguments) it checks GitHub's latest release and, for a newer one, shows a notice and an **Update** button at the top, which downloads this build's file, checks it, replaces only the program's files, and restarts. `roms/` and `cfg/` are left as they are.
- On a Steam Deck the same process becomes the new version, so Steam does not take the run as ended, even in game mode.
- The Update button appears only in a folder a release archive was unpacked into; to turn the check off, write `check_updates = 0` under `[Launcher]` in `cfg/re2dj.ini`.
- Release files are now named `re2DJ-v<version>-<platform>`; the executable inside is still `re2dj` (`re2dj.exe`).
- Installing on a Steam Deck and updating: the [launcher update guide](../guides/launcher-update.md)

## Resolved issues

- [#17](https://github.com/reexec/re2DJ/issues/17) Launcher self-update and re2DJ-v* artifact names (rePIU #48) — PR [#18](https://github.com/reexec/re2DJ/pull/18)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- A real update on Linux from the v0.0.70 release: download, check, replacement and restart in the same process
- A real replacement on Windows is still to be checked

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
