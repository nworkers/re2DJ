# re2DJ v0.0.68

## 변경 사항

- EZ2DJ 6th를 HDD에 둔 CHD로 플레이할 때 생기던 멈칫거림과 배경음 끊김을 줄였습니다. 게임이 곡 배경음처럼 파일을 조금씩 읽기 시작하면, re2DJ가 그 파일 전체를 백그라운드에서 미리 메모리에 읽어 둡니다. 플레이 중에는 디스크를 기다리지 않습니다.
- 6th SpaceMix 플레이 중 25ms를 넘던 파일 읽기(최대 481.9ms)와 40ms를 넘던 프레임이 모두 사라졌습니다. 곡 배경음(14~20MB)은 곡이 시작되기 전에 0.2~0.6초 만에 다 읽힙니다.
- 실행 로그에 미리 읽기가 `files: prefetch …`, `files: prefetched … in N ms`로 남습니다.
- 곡 로딩과 화면 전환 때 처음 읽는 파일이 많으면 HDD에서는 여전히 1~3초 멈출 수 있습니다. SSD에 두면 짧아집니다.

## English

# re2DJ v0.0.68

## Changes

- Playing EZ2DJ 6th from a CHD on an HDD no longer stutters or breaks up the background music. When the game starts reading a file a little at a time, as it does a song's music, re2DJ reads the whole file into memory in the background, so play never waits on the disk.
- During 6th's SpaceMix, file reads over 25 ms (up to 481.9 ms) and frames over 40 ms are gone; a song's music (14 to 20 MB) is read whole in 0.2 to 0.6 s before the song begins.
- The run log records the prefetch as `files: prefetch …` and `files: prefetched … in N ms`.
- Song loading and screen transitions that read many files for the first time can still pause for 1 to 3 s on an HDD; an SSD shortens them.

## Resolved issues

- [#9](https://github.com/reexec/re2DJ/issues/9) Prefetch CHD files in the background to avoid stalls during play — PR [#10](https://github.com/reexec/re2DJ/pull/10)

## Validation

- Windows x86, Linux x64 (gcc, clang) and Linux x86 builds and tests pass on GitHub Actions
- 6th's SpaceMix played by hand on Windows with no stutter or break-up, and a 35-minute attract run with no slow read during a song
- Dev log: [Why the Music Broke Up: Prefetching CHD Files So the Main Thread Never Waits on the HDD](../post/2026-10-09-000009-chd-file-prefetch-wip.md)

Original game executables, HDD data, CHD images and Hardlock material (`cfg/`) are not included in release packages.
