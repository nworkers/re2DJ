- 측정: 설계의 표와 같다.
  *Measured as in the design's table.*
- 첫 테스트는 이미 활성인 창이 있는 상태에서 두 번째 창을 보여서 실패했다. Windows라면 기존 창에 비활성화 메시지를 보내는 경우라, 모델 밖으로 멈추게 하고 테스트는 창 하나로 따로 만들었다.
  *The first test showed a second window while another was active, which Windows answers with deactivation messages to the other window; that case now stops, and the test uses a single window.*
- 결과: Windows x86 CTest 6개 통과(단위 4619 checks), Linux x64·x86 CTest 4개 통과(단위 4616 checks), 실패 0. 사용자 지시대로 긴 실제 실행 회귀는 하지 않았다. 4th가 쓰는 `WS_VISIBLE` 생성 경로는 기존 단위 테스트가 같은 메시지 순서를 확인한다.
  *Windows x86: all 6 CTest tests pass (4619 unit checks); Linux x64 and x86: all 4 CTest tests pass (4616 unit checks); no failures. Per the user's direction no long real-run regression was made; the existing unit test still checks the message sequence of the `WS_VISIBLE` creation 4th uses.*
- Linux 1st(x64): `ShowWindow`를 지나 메시지 루프(`PeekMessageA`, `GetAsyncKeyState`)를 돌고, 호출 941번째 `user32!EnumDisplaySettingsA`에서 멈춘다.
  *Linux 1st (x64) gets past `ShowWindow` into its message loop (`PeekMessageA`, `GetAsyncKeyState`) and stops at `user32!EnumDisplaySettingsA` (call 941).*
