## 진행 / Progress

Windows `--audio-volume-trace`로 게임의 mixer 호출을 보려 했다. 4th는 import를 보호 코드가 다시 짜므로 IAT 이름 교체가 걸리지 않았고, 호출은 기록되지 않았다. 그래서 host mixer를 직접 측정하고, 측정한 경계 전체를 구현했다(측정값은 설계 문서에 있다).

*Windows `--audio-volume-trace` was tried to see the game's mixer calls, but the 4th's protection rebuilds its imports, so swapping IAT entries by name never caught them and nothing was recorded. The host mixer was therefore measured directly and the whole measured boundary implemented (the measurements are in the design).*

Linux 실행에서 게임은 `mixerGetNumDevs` → 1, `mixerOpen(&h, 0, 0, 0, 0)` → 0을 부른다. 그 뒤로 line이나 control을 조회하지 않고 진행한다.

- event를 만들고 `timeGetTime`을 부른다.
- secondary sound buffer를 만들고 복제한다.
- `dsound.dll!IDirectSoundBuffer::Stop`에서 멈춘다.

*In the Linux run the game calls `mixerGetNumDevs` → 1 and `mixerOpen(&h, 0, 0, 0, 0)` → 0, then carries on without querying any line or control:*

- *It creates events and calls `timeGetTime`.*
- *It creates and duplicates its secondary sound buffers.*
- *It stops at `dsound.dll!IDirectSoundBuffer::Stop`.*

게임이 처음으로 `timeGetTime`을 부르는 구간까지 오면서, 폭 비교에 시계 값 차이가 드러났다. 비교 script는 이제 `timeGetTime` 반환값도 가린다.

*With the game now reaching its first `timeGetTime` calls, clock values showed up as differences in the width comparison; the comparison script now masks `timeGetTime` results too.*
