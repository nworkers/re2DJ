# 작업 로그: ez2dj3rd IO 입력 연동 및 키보드 입력 지원

## 한국어

### 작업 요약

`ez2dj3rd` 실행 시 키보드 입력(`--io-config`)이 동작하지 않던 원인을 규명하고 해결했습니다.
`Ez2DjKeyboardInput`의 키 이름 파싱에 `TAB` 및 주요 특수 키들을 추가하고, `--io-config` 인자를 절대 경로로 정규화하여 게스트 임시 작업 디렉터리 경로 불일치 문제를 해결했으며, 메모리 분석을 통해 확인된 `ez2dj3rd`의 raw I/O Helper RVA(`0x000a9887`, `0x000a98bb`)를 타깃 프로파일에 등록했습니다.

### 원인 분석

1. **`ParseKey`의 `TAB` 미지원으로 인한 초기화 영구 실패**:
   `config/ez2dj-io.example.ini`에 1P 턴테이블 키(`p1_positive=TAB`)가 설정되어 있었으나, `Ez2DjKeyboardInput::ParseKey` 함수에 `TAB` 키 처리가 누락되어 있었습니다. 이로 인해 `Ez2DjKeyboardInput::Initialize`가 `"unknown key name for turntables.p1_positive: TAB"` 에러를 반환하며 실패하고 `g_keyboard_input_state = 2`(에러 상태)로 전환되어, 런타임 수명 동안 키보드 폴링이 전면 중단되었습니다.

2. **상대 경로 전달 시 게스트 작업 디렉터리 불일치**:
   CLI에서 `--io-config .\config\ez2dj-io.example.ini`와 같이 상대 경로로 전달할 경우, 게스트 프로세스의 작업 디렉터리가 CHD 임시 압축 해제 디렉터리(`%TEMP%/re2dj/chd/ez2dj3rd/EZ2DJ`)로 변경되므로 `GetPrivateProfileStringA`가 해당 디렉터리 기준으로 파일을 탐색하여 찾지 못하고 모든 키를 `0`(`"NONE"`)으로 초기화했습니다.

3. **`ez2dj3rd` Legacy I/O Helper RVA 미확정 상태**:
   `src/target/target_profile.cpp`에서 3rd 프로파일은 `legacy_io_in_byte_rva = 0`, `legacy_io_out_byte_rva = 0`, `legacy_io_port_range_fallback = true`로 설정되어 있었습니다.

## English

### Summary

Investigated and resolved the issue where keyboard input (`--io-config`) was non-functional when running `ez2dj3rd`.
Extended key parsing in `Ez2DjKeyboardInput` to support `TAB` and key navigation/modifier keys, canonicalized `--io-config` to an absolute path to resolve the guest temporary working directory mismatch, and configured the confirmed raw I/O helper RVAs (`0x000a9887`, `0x000a98bb`) in the `ez2dj3rd` target profile.

### Root Cause Analysis

1. **`ParseKey` Missing `TAB` Causing Permanent Input Initialization Failure**:
   `config/ez2dj-io.example.ini` configured 1P turntable clockwise rotation as `p1_positive=TAB`. However, `Ez2DjKeyboardInput::ParseKey` had no mapping for `TAB`. As a result, `Ez2DjKeyboardInput::Initialize` failed with `"unknown key name for turntables.p1_positive: TAB"`, setting `g_keyboard_input_state = 2` (error state), which permanently disabled all keyboard polling for the process lifetime.

2. **Guest Working Directory Mismatch with Relative Config Paths**:
   When `--io-config .\config\ez2dj-io.example.ini` was passed as a relative path, the guest process working directory was set to the temporary CHD extraction folder (`%TEMP%/re2dj/chd/ez2dj3rd/EZ2DJ`). `GetPrivateProfileStringA` resolved the relative path against that temporary folder, failing to find the file and defaulting all key mappings to `0` (`"NONE"`).

3. **Unconfirmed Legacy I/O Helper RVAs for `ez2dj3rd`**:
   In `src/target/target_profile.cpp`, `ez2dj3rd` had `legacy_io_in_byte_rva = 0`, `legacy_io_out_byte_rva = 0`, and `legacy_io_port_range_fallback = true`.
   Disassembly of decrypted memory confirmed that the `in al, dx` helper is at `0x004A9880` (instruction RVA `0x000A9887`) and `out dx, al` helper is at `0x004A98B0` (instruction RVA `0x000A98BB`), and port assignments (`0x101`, `0x102`, `0x106`, `0x103`, `0x104`, `0x105`) match `Ez2DjIoBoard` exactly.

### Applied Changes

1. **Keyboard Parsing Extension (`src/platform/windows/ez2dj_keyboard_input.cpp`)**:
   - Added support in `ParseKey` for `TAB` (`VK_TAB`), `ESCAPE`/`ESC`, `LSHIFT`, `RSHIFT`, `SHIFT`, `LCONTROL`/`LCTRL`, `RCONTROL`/`RCTRL`, `CONTROL`/`CTRL`, `LMENU`/`LALT`, `RMENU`/`RALT`, `ALT`, `BACKSPACE`/`BACK`, `CAPITAL`/`CAPSLOCK`/`CAPS`, `INSERT`, `DELETE`/`DEL`, `HOME`, `END`, `PAGEUP`/`PGUP`, `PAGEDOWN`/`PGDN`.
2. **Absolute Path Canonicalization**:
   - `src/host/cli/main.cpp`: Canonicalize `--io-config` argument to `std::filesystem::absolute`.
   - `src/tools/windows_x86_launcher_probe/main.cpp`: Canonicalize `--io-config` argument to `std::filesystem::absolute`.
3. **Target Profile Configuration (`src/target/target_profile.cpp`)**:
   - Set `legacy_io_in_byte_rva = 0x000a9887`, `legacy_io_out_byte_rva = 0x000a98bb`, and disabled `legacy_io_port_range_fallback` for `ez2dj3rd`.
   - Updated profile note.
4. **Unit Tests & Build Registration**:
   - `tests/unit/ez2dj_keyboard_input_test.cpp`: Added unit tests verifying `Ez2DjKeyboardInput` parsing and INI loading.
   - `tests/unit/target_profile_test.cpp`: Updated `ez2dj3rd` helper RVA and fallback expectations.
   - `src/tools/windows_product_loader_probe/main.cpp`: Updated launcher argument assertions.
   - `CMakeLists.txt`: Added `re2dj_ez2dj_keyboard_input_test` executable and test.
