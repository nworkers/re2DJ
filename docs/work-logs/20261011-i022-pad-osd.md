# #22 작업 로그 — 게임패드로 OSD 열기와 조작 / #22 work log — opening and driving the OSD with a gamepad

설계: [20261011-i022-pad-osd.md](../design/20261011-i022-pad-osd.md) · 지시서: [20261011-i022-pad-osd.md](../work-orders/20261011-i022-pad-osd.md)

## 2026-10-11

- **조사**: rePIU `33eba35`(v0.0.217, #55)의 설계와 `pad_osd_chord.{h,cpp}`를 읽었다. LT+RT+Y의 가장자리로 토글, 열려 있는 동안 패드 → OSD, 게임 입력 관문(막힘 중 0, 풀릴 때 눌린 입력은 뗄 때까지 숨김), B로 닫기(직전 프레임에 메뉴가 없을 때), 키보드는 그대로. re2DJ OSD는 ImGui 플랫폼 backend 없이 호스트가 넣는 마우스 입력만 받았다. re2DJ의 EZ2DJ 기본 배치에서는 LT·RT가 이펙터 3·4, Y가 1P 4번 키라 조합을 이루는 동안은 게임에도 들어간다(설계에 기록).
- **구현**
  - `re2dj/input/pad_osd_chord.h`(헤더만): `IsPadOsdChordDown`(한 패드 / 목록), `PadChordEdge`, `PadGameGate`(`GamepadControls` 단위).
  - OSD: `SetGamepad`, 바뀐 입력을 `AddKeyAnalogEvent`로 ImGui 게임패드 키(D-pad, 네 face, L1·R1, Start·Back, 왼쪽 스틱 네 방향)에 전달, `NavEnableGamepad`·`HasGamepad`, 열릴 때 `SetNextWindowFocus`, B 눌림이고 직전 프레임에 열린 팝업이 없으면 닫기.
  - `SdlHostPresentation::Present`: `ReadEach()`로 읽은 뒤 OSD 조합 가장자리에 토글과 로그(`input: gamepad OSD chord (LT+RT+Y): OSD shown/hidden`), 관문을 OSD 표시 여부에 맞춰 게스트 입력을 거르고, 표시 중이면 OSD에 넘김. 종료 조합(#20)은 관문 앞 상태로 본다.
- 문서: README의 OSD 문단, 런처 업데이트 가이드의 스팀덱 절, IMPLEMENTED.

  *Investigation: read rePIU `33eba35` (v0.0.217, #55), its design and `pad_osd_chord.{h,cpp}`: LT+RT+Y's rising edge toggles, the pad drives the OSD while it is open, a game-input gate (zero while closed off, input held as it reopens hidden until released), B closing it when no menu was open the frame before, the keyboard unchanged. re2DJ's OSD took only the mouse input the host hands it, with no ImGui platform backend; in re2DJ's EZ2DJ default LT and RT are effectors 3 and 4 and Y player 1's key 4, so the chord's buttons reach the game while it is being formed (recorded in the design). Implementation: `re2dj/input/pad_osd_chord.h` (header-only) with `IsPadOsdChordDown` (one pad or a list), `PadChordEdge` and `PadGameGate` over `GamepadControls`; the OSD gains `SetGamepad`, passes changed controls to ImGui's gamepad keys through `AddKeyAnalogEvent` (the d-pad, the four faces, L1 and R1, Start and Back, and the left stick's four directions), turns on `NavEnableGamepad` and `HasGamepad`, focuses with `SetNextWindowFocus` as it opens, and closes on a B press when no popup was open the frame before; `SdlHostPresentation::Present` reads `ReadEach()`, toggles on the chord's rising edge with a log line (`input: gamepad OSD chord (LT+RT+Y): OSD shown/hidden`), filters the guest's input through the gate as the OSD shows, and hands the pads to the OSD while it shows, the exit chord (#20) still reading the state ahead of the gate. Documents: the README's OSD paragraph, the launcher update guide's Steam Deck section, IMPLEMENTED.*
