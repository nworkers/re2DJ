## 2026-10-10

- **조사**: v0.0.71 CI(`38049513343`)와 v0.0.70 릴리스(`38045538035`)의 annotation은 두 가지였다. Node.js 20 지원 종료 경고(`actions/checkout@v4`, `actions/cache@v4`, `actions/upload-artifact@v4`, `actions/download-artifact@v4`)와 "`ubuntu-latest` label will migrate to Ubuntu 26 beginning October 19, 2026" 안내다. 각 액션 최신 주 버전(checkout v7.0.1, cache v6.1.0, upload-artifact v7.0.2, download-artifact v8.0.2)이 `node24`이고, v4 이후 릴리스 노트의 깨지는 변경은 이 저장소의 사용 방식(이름 패턴, `merge-multiple: true`)에 영향이 없다. 개발 PC(Ubuntu 26.04.1, GCC 15.2, clang 21.1.8)에 CI의 apt 패키지 21개가 모두 있다.
- **변경**: `ci.yml`·`release.yml`의 액션을 checkout v7, cache v6, upload-artifact v7, download-artifact v8로 올리고, Linux runner를 `ubuntu-26.04`로 고정했다(`ci.yml`, `release.yml`, `pages.yml`). 릴리스의 Debian 12 컨테이너와 glibc 상한 2.36은 그대로다.

  *Investigation: the v0.0.71 CI (`38049513343`) and v0.0.70 release (`38045538035`) carried two annotations: the Node.js 20 deprecation warning (`actions/checkout@v4`, `actions/cache@v4`, `actions/upload-artifact@v4`, `actions/download-artifact@v4`) and "`ubuntu-latest` label will migrate to Ubuntu 26 beginning October 19, 2026". Each action's latest major (checkout v7.0.1, cache v6.1.0, upload-artifact v7.0.2, download-artifact v8.0.2) runs `node24`, and the breaking changes in their release notes since v4 do not touch this repository's use (name patterns, `merge-multiple: true`); the development PC (Ubuntu 26.04.1, GCC 15.2, clang 21.1.8) carries all 21 apt packages CI installs. Change: `ci.yml` and `release.yml` moved to checkout v7, cache v6, upload-artifact v7 and download-artifact v8, and the Linux runners were pinned to `ubuntu-26.04` (`ci.yml`, `release.yml`, `pages.yml`); the release's Debian 12 containers and glibc limit of 2.36 are unchanged.*
