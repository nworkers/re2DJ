# #12 작업 로그 — 인자 없이 실행했을 때 띄우는 런처 / #12 work log — a launcher shown when run without arguments

설계: [20261010-i012-launcher.md](../design/20261010-i012-launcher.md) · 지시서: [20261010-i012-launcher.md](../work-orders/20261010-i012-launcher.md)

## 2026-10-10 — 조사 / Investigation

- rePIU의 런처(설계 500·502, `src/launcher/`, `src/host/loader/main.cpp`)를 읽었다. 인자가 없으면 ImGui 창에 롬셋 목록·가용 여부·사유와 옵션을 보여 주고, 고른 롬셋을 새 프로세스로 실행한 뒤 런처로 돌아온다. 같은 프로세스에서 실행하려던 첫 시도는 GPU 드라이버가 게스트 저주소 공간을 먼저 차지해 실패했다고 기록돼 있다.
- re2DJ는 인자가 없으면 사용법을 출력하고 종료 코드 1로 끝난다. Windows x86은 시작 때 자기 자신을 재실행해 `0x400000`부터 64MiB를 예약하므로, 같은 이유로 새 프로세스 실행을 택했다. 옵션은 모두 명령줄 옵션이라 환경 변수가 아니라 옵션으로 넘긴다.

  *Read rePIU's launcher (designs 500 and 502, `src/launcher/`, `src/host/loader/main.cpp`): run bare, it shows the ROM sets, their availability and reasons and options in an ImGui window, starts the chosen set as a new process and returns to the launcher; its notes record that a first attempt in the same process failed because the GPU driver took the guest's low address space first. re2DJ run bare printed its usage and exited with code 1. Windows x86 restarts itself at start to reserve 64 MiB from `0x400000`, so for the same reason the game runs in a new process; every option is a command-line option, so options rather than environment variables carry the settings.*

## 2026-10-10 — 구현 / Implementation

- `hdd/chd_image_locator.{h,cpp}`: `main.cpp`의 `FindChdImage`를 그대로 옮기고, 결과 종류(`ChdImageLookup`)를 돌려주는 `LocateChdImage`를 더했다. 명령줄 shortcut과 런처가 같은 규칙을 쓴다.
- `launcher/launcher_catalog.{h,cpp}`: 내장 프로필(중복 id는 한 번)마다 현재 디렉터리 기준으로 `Ready`·`No CHD`·`Several CHDs`·`No directory`와 사유, 프로필 기본 소리 크기.
- `launcher/launcher_settings.{h,cpp}`: `cfg/re2dj.ini`(`[Launcher] last_profile`, `[Video] fullscreen`·`color_depth`·`post_shader`, `[Audio] gain_db`) 읽기·쓰기. 잘못된 값은 경고 후 무시한다. 고른 값만 자식 옵션(`--fullscreen`/`--windowed`, `--color-depth`, `--post-shader=`, `--audio-gain-db`)이 된다.
- `platform/self_process.h`와 `linux/self_process.cpp`(`posix_spawn("/proc/self/exe")`, `waitpid`), `windows/self_process.cpp`(`GetModuleFileNameA`, `QuoteCommandLineArgument`, `CreateProcessA`, `GetExitCodeProcess`).
- `ui/launcher_screen.{h,cpp}`: ImGui 화면. 프로필 표, 고른 행의 경로나 사유, 옵션, 직전 실행 결과, Start/Quit. Enter·Space·패드 확인·더블클릭으로 시작, Esc로 종료.
- `platform/sdl/launcher_window.{h,cpp}`: SDL3 창, OpenGL 2.1 호환 컨텍스트, ImGui SDL3·OpenGL3 backend, 이벤트 루프. 돌아가기 전에 창과 컨텍스트를 모두 닫는다. CMake에 `re2dj_imgui_sdl3`(경고 옵션 없이 ImGui backend만)와 `re2dj_launcher_ui`를 더했다.
- `host/cli/launcher_session.{h,cpp}`와 `main.cpp`: 인자가 없고 `RE2DJ_LAUNCHER`가 `0`이 아니면 런처 루프. 창을 한 번도 열지 못하면 기존처럼 사용법을 출력한다. 사용법 첫머리에 런처를 적었다.
- 단위 테스트 `tests/unit/launcher_test.cpp`: CHD 판정 다섯 경우, 카탈로그 상태와 사유·내장 표(중복 없음, 6th·1st가 기본 경로에서 Ready), 설정 파싱(대소문자·CRLF·따옴표, 잘못된 값 경고, 범위 끝값), 파일 왕복, 고른 값만 저장, 자식 인자 순서.
- 문서: `ARCHITECTURE.md` 계층 표, README 런처 절과 명령행, `docs/IMPLEMENTED.md`, `src/launcher/README.md`, `src/platform/{linux,windows,sdl}/README.md`.

  *`hdd/chd_image_locator.{h,cpp}` takes `FindChdImage` from `main.cpp` unchanged and adds `LocateChdImage`, which returns how the lookup ended (`ChdImageLookup`), so the command-line shortcut and the launcher share one rule. `launcher/launcher_catalog.{h,cpp}` gives each built-in profile (a repeated id once) `Ready`, `No CHD`, `Several CHDs` or `No directory` under the current directory, with the reason and the profile's default gain. `launcher/launcher_settings.{h,cpp}` reads and writes `cfg/re2dj.ini` (`[Launcher] last_profile`, `[Video] fullscreen`, `color_depth` and `post_shader`, `[Audio] gain_db`), warning about and ignoring bad values, and only chosen values become child options. `platform/self_process.h` has a Linux implementation (`posix_spawn("/proc/self/exe")`, `waitpid`) and a Windows one (`GetModuleFileNameA`, `QuoteCommandLineArgument`, `CreateProcessA`, `GetExitCodeProcess`). `ui/launcher_screen.{h,cpp}` is the ImGui screen: the profile table, the chosen row's path or reason, the options, the previous run's result and Start/Quit, with Enter, Space, the pad's confirm button or a double click starting and Esc quitting. `platform/sdl/launcher_window.{h,cpp}` holds the SDL3 window, the OpenGL 2.1 compatibility context, ImGui's SDL3 and OpenGL3 backends and the event loop, closing the window and context before returning; CMake gains `re2dj_imgui_sdl3` (just the ImGui backend, without the warning options) and `re2dj_launcher_ui`. `host/cli/launcher_session.{h,cpp}` and `main.cpp` run the launcher loop when there are no arguments and `RE2DJ_LAUNCHER` is not `0`, printing the usage as before when no window ever opens; the usage text now starts with the launcher. Unit tests in `launcher_test.cpp` cover five CHD lookups, catalog states and reasons and the built-in table (no repeats, 6th and 1st Ready at their default paths), settings parsing (case, CRLF, quotes, warnings for bad values, the range ends), a file round trip, storing only chosen values, and the child argument order. Documents: the `ARCHITECTURE.md` layer table, the README's launcher section and command line, `docs/IMPLEMENTED.md`, `src/launcher/README.md` and `src/platform/{linux,windows,sdl}/README.md`.*
