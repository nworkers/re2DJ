## 2026-10-04

- **방향**: 사용자가 Windows 주입 경로를 폐기하고 Linux 형태의 로더로 통합하기로 했다. 설계는 다섯 단계(446 공용 러너 추출, 447 SDL host 공용화, 448 Windows x86 backend, 449 Windows CLI 전환, 450 주입 경로 제거)로 나눴고, 이 로그는 446이다.
- **이동**(`git mv`, 이력 유지): Linux 루트의 중립 러너 22개 파일 쌍(PE·thunk·모듈 이미지·SEH·게스트 스레드·runner·continuation·legacy I/O·instruction trace·observation 셋·kernel32 진단·thread probe·fault observation)과 세 계약 헤더, `original_runner.cpp`, `game_controls.*`, `src/platform/native_probe_fixture.*` → `src/platform/native/`. `include/re2dj/platform/linux/original_runner.h` → `include/re2dj/platform/native/`.
- **namespace·경로**: 옮긴 파일과 `linux/x86/`·`linux/x64/`(계약 구현)를 `re2dj::platform::native`로. 헤더 가드는 파일 이름에서 다시 만들었다(`RE2DJ_PLATFORM_NATIVE_<FILE>_H_`). x64 파일 셋의 별칭 `linux_platform`은 `native_platform`으로. CLI는 러너에 `native_platform::`을, SDL host에는 그대로 `linux_platform::`을 쓴다.
- **OS 계약** `native_host_services.h`: `HostPageSize`, `HostMapAt`(정확한 주소 아니면 실패), `HostMapAnywhere`, `HostProtect`, `HostUnmap`, `HostFlushCode`, `HostMonotonicMilliseconds`, `HostSleepMilliseconds`, `HostReadWallClock`. Linux 구현 `linux/native_host_services.cpp`. 공용 10개 파일의 `mmap`·`mprotect`·`munmap`·`__builtin___clear_cache`·`clock_gettime`·`clock_nanosleep`·`sysconf`·`localtime_r`을 이것으로 바꿨다. `MapNativeLowMemory`는 `HostProtection`을 받고, 두 폭 구현은 `linux/native_host_protection.h`의 `PosixProtection`으로 바꿔 쓴다.
- **fault 종류**: `NativeGuestFault`에 `NativeFaultKind kind`. 두 폭의 bootstrap이 `linux/native_signal_fault.h`의 `NativeFaultKindFromSignal`로 채우고, 스레드 종료의 합성 fault는 `kAccessViolation`. 공용 다섯 파일의 `SIGTRAP`·`SIGILL` 비교를 `kBreakpoint`·`kIllegalInstruction`으로 바꾸고 `<signal.h>`를 뺐다. `status_code`는 로그용으로 그대로 시그널 번호다.
- **확인**: `src/platform/native/`에 `mmap`·`mprotect`·`munmap`·`PROT_`·`clock_`·`sysconf`·`localtime_r`·`__builtin`·`<sys/`·`<unistd.h>`·`<time.h>`·`<signal.h>`가 없다(`grep` 결과 0건). 남은 시그널 언급은 두 주석뿐이며 OS 중립 문구로 고쳤다.
- **문서**: 새 `src/platform/native/README.md`, `src/platform/linux/README.md` 구성 문단, AGENTS.md(디렉터리 규칙, 아키텍처 규칙의 실행 경로), 헌장(Windows·Linux 실행 방향), ARCHITECTURE(실행 모델, 계층 표, game controls 경로).

  *Direction: the user decided to retire Windows injection for the Linux-style loader; the design has five phases (446 extract the shared runner, 447 share the SDL hosts, 448 the Windows x86 backend, 449 switch the Windows CLI, 450 remove injection), and this log is 446. Moved with `git mv`, keeping history: the Linux root's neutral runner files, the three contract headers, `original_runner.cpp`, `game_controls.*` and `src/platform/native_probe_fixture.*` to `src/platform/native/`, and the public `original_runner.h` to `include/re2dj/platform/native/`. The moved files and `linux/x86/` and `linux/x64/` (the contract implementations) use `re2dj::platform::native`, header guards rebuilt from file names, the x64 alias `linux_platform` renamed `native_platform`, and the CLI uses `native_platform::` for the runner and `linux_platform::` for the SDL hosts. The OS contract `native_host_services.h` (`HostPageSize`, `HostMapAt` exact-or-fail, `HostMapAnywhere`, `HostProtect`, `HostUnmap`, `HostFlushCode`, `HostMonotonicMilliseconds`, `HostSleepMilliseconds`, `HostReadWallClock`), implemented in `linux/native_host_services.cpp`, replaces `mmap`, `mprotect`, `munmap`, `__builtin___clear_cache`, `clock_gettime`, `clock_nanosleep`, `sysconf` and `localtime_r` in ten shared files; `MapNativeLowMemory` takes a `HostProtection`, both width implementations converting it through `PosixProtection` in `linux/native_host_protection.h`. `NativeGuestFault` gains `NativeFaultKind kind`, filled by both widths' bootstraps through `NativeFaultKindFromSignal` in `linux/native_signal_fault.h`, `kAccessViolation` for the synthetic fault of a thread's end; five shared files compare `kBreakpoint` and `kIllegalInstruction` instead of `SIGTRAP` and `SIGILL` and drop `<signal.h>`, while `status_code` stays the signal number for logs. `grep` finds none of `mmap`, `mprotect`, `munmap`, `PROT_`, `clock_`, `sysconf`, `localtime_r`, `__builtin`, `<sys/`, `<unistd.h>`, `<time.h>` or `<signal.h>` under `src/platform/native/`; the two comments still naming signals now read OS-neutrally. Documents: a new `src/platform/native/README.md`, the layout paragraph of `src/platform/linux/README.md`, AGENTS.md (directory rules and the execution-path architecture rule), the charter (Windows and Linux execution direction), and ARCHITECTURE (execution model, layer table, game-controls path).*
