- `#459482 FindFirstFileA("system\StreetMix\panel\STYLE_StreetMix*_0.pvi")`가 handle을 돌려주었다.

전체 기록(113MB)은 확인 뒤 지웠다.

*In a real Linux run (x64, `SDL_VIDEO_DRIVER=x11`), XTest sent F5 three times and 1 at 20 seconds, and 1 again 12 seconds later. The default API log span (32,768 calls) did not reach the search, so the run was repeated with the new `--api-log-calls 0` and `--call-limit 500000`. The result:*

- *`#459482 FindFirstFileA("system\StreetMix\panel\STYLE_StreetMix*_0.pvi")` returned a handle.*
- *`FindNextFileA` succeeded nine times, then returned 18 (ten in all).*
