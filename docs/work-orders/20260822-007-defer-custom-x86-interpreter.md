# 작업 지시: 직접 x86 인터프리터 후순위화

## 목표

직접 x86-32 인터프리터 구현을 후순위로 옮기고, 다음 작업을 실행 backend 경계 설계와 데스크톱 네이티브 helper 및 Web 실행 엔진 조사로 재정의합니다.

## Goal

Move custom x86-32 interpreter implementation to a later priority and redefine the next work around the execution-backend boundary, desktop native-helper feasibility, and Web execution-engine research.

## 범위

* 포팅 단계와 TODO 우선순위 갱신
* 현재 아키텍처의 backend 정책 갱신
* 64비트·Web 호스트 실행 지식 문서의 기존 결론 교정
* 프로젝트 헌장의 직접 실행 가능성 설명 교정

## 검증

관련 문서에서 인터프리터가 더 이상 즉시 기준 구현으로 표현되지 않고, Web 실행 계층의 필요성과 프로젝트 라이선스 정책은 그대로 유지되는지 검색으로 확인합니다.

## Verification

Search the relevant documents to ensure the interpreter is no longer described as the immediate baseline implementation while preserving the need for a Web execution layer and the project license policy.
