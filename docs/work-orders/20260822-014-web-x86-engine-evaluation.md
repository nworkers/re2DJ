# 작업 지시: Web x86 실행 엔진 평가

## 목표

허용 라이선스 범위에서 Web용 x86 실행 엔진을 조사하고, `ExecutionBackend` 후보와 다음 검증 작업을 결정한다.

## 작업 범위

1. 공식 저장소, 공식 문서, 라이선스 원문을 확인한다.
2. Web 실행 가능성, IA-32 기능, CPU 코어 분리성, import gate 연동 가능성을 비교한다.
3. copyleft 또는 구조적 부적합 후보는 이유와 함께 제외한다.
4. 지식 기반, TODO, 포팅 계획과 Web 플랫폼 문서를 갱신한다.
5. 실제 라이브러리나 소스 코드는 도입하지 않는다.

## 검증

- 문서 링크와 라이선스 분류를 공식 원문에 대조한다.
- 저장소 문서의 한영 병기와 상태 표현이 일치하는지 확인한다.
- 변경 파일에 원본 게임 자산이나 후보 엔진 소스가 포함되지 않았는지 확인한다.

# Work Order: Web x86 Execution Engine Evaluation

## Objective

Investigate Web x86 execution engines under permitted licenses and decide on an `ExecutionBackend` candidate and the next validation task.

## Scope

1. Inspect official repositories, documentation, and original license texts.
2. Compare Web viability, IA-32 capability, CPU-core separability, and import-gate integration potential.
3. Exclude copyleft or structurally unsuitable candidates with reasons.
4. Update the knowledge base, TODO, porting plan, and Web platform documentation.
5. Do not introduce any library or source code.

## Verification

- Cross-check documentation links and license classifications against official originals.
- Check that Korean and English sections and status statements agree.
- Confirm that no original game asset or candidate-engine source was added.
