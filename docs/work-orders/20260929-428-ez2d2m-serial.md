# 작업 428 작업 지시서 — ez2d2m이 열지 못한 COM1 핸들 / Task 428 work order — the COM1 handle ez2d2m fails to open

설계: [20260929-428-ez2d2m-serial.md](../design/20260929-428-ez2d2m-serial.md)

## 절차 / Steps

1. 사용자 로그의 멈춘 호출을 복호화 이미지에서 따라가 시리얼 클래스의 열기·쓰기·닫기 흐름을 확인한다.
   *Follow the stopped call through the decrypted image to the serial class's open, write, and close.*
2. 그 흐름의 호출을 Windows 11에서 무효 핸들로 측정한다.
   *Measure those calls on Windows 11 with invalid handles.*
3. kernel32 facade에 측정값을 모델하고 단위 테스트를 만든다.
   *Model the measurements in the kernel32 facade and add unit tests.*
4. Linux 두 폭과 Windows에서 테스트한다. 두 폭에서 ez2d2m에 코인을 넣어 실행하고, Windows 제품에도 코인을 넣어 비교한다.
   *Test on both Linux widths and Windows; run ez2d2m with coins on both widths, and on the Windows product for comparison.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux ez2d2m이 두 폭에서 코인을 넣은 뒤에도 멈추지 않는다.
  *Linux ez2d2m does not stop after coins on either width.*
