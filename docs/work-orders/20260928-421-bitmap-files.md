# 작업 421 작업 지시서 — 파일에서 읽는 비트맵 / Task 421 work order — bitmaps loaded from files

설계: [20260928-421-bitmap-files.md](../design/20260928-421-bitmap-files.md)

## 절차 / Steps

1. 복호화 이미지에서 1st SE의 비트맵 경로를 확인하고, Windows에서 관련 API를 측정한다.
   *Confirm 1st SE's bitmap path in the decrypted image and measure the APIs involved on Windows.*
2. 공용 `ParseBitmapFile`, user32 `LoadImageA`, gdi32 `GetObjectA`·`CreateCompatibleDC`·`SelectObject`·`StretchBlt`·`DeleteDC`와 `DeleteObject`의 비트맵 처리를 구현한다.
   *Add the shared `ParseBitmapFile`, user32 `LoadImageA`, gdi32 `GetObjectA`, `CreateCompatibleDC`, `SelectObject`, `StretchBlt`, and `DeleteDC`, and bitmap handling in `DeleteObject`.*
3. 측정을 단위 테스트로 옮기고, Linux 두 폭과 Windows에서 테스트하고, Linux 1st SE를 실행한다.
   *Carry the measurements into unit tests, test on both Linux widths and Windows, and run Linux 1st SE.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux 1st SE가 `LoadImageA`와 그 뒤의 비트맵 복사를 지난다.
  *Linux 1st SE gets past `LoadImageA` and the bitmap copy after it.*
