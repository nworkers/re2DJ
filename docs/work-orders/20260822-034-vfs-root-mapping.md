# VFS mount root mapping 작업 지시

1. 공용 VFS root resolver를 추가한다.
2. `C:\\windows` support mount와 `D:\\ez2dj` HDD mount를 분리한다.
3. overlay-first read와 overlay-only write 경로를 구성한다.
4. Win32 build와 CTest를 검증한다.

## English

1. Add the shared VFS root resolver.
2. Separate the `C:\\windows` support mount from the `D:\\ez2dj` HDD mount.
3. Establish overlay-first reads and overlay-only writes.
4. Verify the Win32 build and CTest.
