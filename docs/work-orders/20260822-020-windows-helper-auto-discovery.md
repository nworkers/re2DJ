# Windows Helper Auto-Discovery

## 한국어

1. observer에서 `--helper`를 선택 인자로 바꿉니다.
2. Windows host executable 기준의 bundled helper 탐색을 추가합니다.
3. override와 탐색 실패를 Windows Debug 빌드로 검증합니다.

## English

1. Make `--helper` optional in the observer.
2. Add bundled-helper discovery relative to the Windows host executable.
3. Verify override and discovery-failure paths with a Windows Debug build.
