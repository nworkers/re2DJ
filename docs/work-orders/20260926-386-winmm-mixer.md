# 작업 386 작업 지시서 — winmm mixer / Task 386 work order — the winmm mixer

설계: [20260926-386-winmm-mixer.md](../design/20260926-386-winmm-mixer.md)

## 절차 / Steps

1. 32비트 PowerShell로 host mixer를 측정한다(장치, line, control, 값, 오류).
   *Measure the host mixer from 32-bit PowerShell (device, lines, controls, values, errors).*
2. `guest_mixer.h/.cpp` 모델을 만들고 `GuestProcess`에 둔다.
   *Build the `guest_mixer.h/.cpp` model and hold it in `GuestProcess`.*
3. winmm mixer handler 일곱 개를 구현한다.
   *Implement the seven winmm mixer handlers.*
4. 단위 테스트와 문서.
   *Unit tests and documentation.*

## 완료 조건 / Done when

- Windows x86과 Linux 두 폭이 build와 CTest를 통과한다.
  *Windows x86 and both Linux widths build and pass CTest.*
- Linux 실제 4th가 두 폭에서 mixer를 열고 그 뒤로 진행한다.
  *On both Linux widths the real 4th opens the mixer and continues past it.*
