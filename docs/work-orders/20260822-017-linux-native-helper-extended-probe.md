# Linux Native Helper Extended Probe

## 한국어

1. Linux host probe fixture를 named/ordinal import, TLS, relocation이 있는 합성 PE32로 교체합니다.
2. `NativeHelperBackend`를 통해 import memory read/write와 completion을 검증합니다.
3. Linux x64/i386 결합 probe를 실행하고 결과를 작업 로그에 기록합니다.

## English

1. Replace the Linux host fixture with a synthetic PE32 containing named/ordinal imports, TLS, and relocations.
2. Verify import memory read/write and completion through `NativeHelperBackend`.
3. Run the Linux x64/i386 integration probe and record the result in a work log.
