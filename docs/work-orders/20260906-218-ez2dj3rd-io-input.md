# EZ2DJ 3rd IO 입력 연동 및 키보드 입력 수정 작업 지시서

## 한국어

### 작업 목표

`ez2dj3rd` 실행 시 키보드 입력(`--io-config`)이 정상적으로 동작하도록 `Ez2DjKeyboardInput`의 키 이름 파싱을 확장하고, 설정 파일 경로를 절대 경로로 정규화하며, `ez2dj3rd` 프로파일에 메모리 분석으로 확인된 I/O Helper RVA를 등록합니다.

### 세부 작업 항목

1. **`src/platform/windows/ez2dj_keyboard_input.cpp`의 `ParseKey` 확장**:
   - `TAB` (`VK_TAB`), `ESCAPE`/`ESC`, `LSHIFT`, `RSHIFT`, `SHIFT`, `LCONTROL`/`LCTRL`, `RCONTROL`/`RCTRL`, `CONTROL`/`CTRL`, `LMENU`/`LALT`, `RMENU`/`RALT`, `ALT`, `BACKSPACE`/`BACK`, `CAPITAL`/`CAPSLOCK`/`CAPS`, `INSERT`, `DELETE`/`DEL`, `HOME`, `END`, `PAGEUP`/`PGUP`, `PAGEDOWN`/`PGDN` 등 주요 키 지원 추가.
2. **`io_config` 경로 절대 경로 정규화**:
   - `src/host/cli/main.cpp`: `--io-config` 인자 수신 시 `std::filesystem::absolute`로 변환.
   - `src/platform/windows/original_process_backend.cpp`: 인자 전달 시 절대 경로 문자열 전달.
   - `src/tools/windows_x86_launcher_probe/main.cpp`: `--io-config` 인자 수신 시 절대 경로로 정규화.
3. **`src/target/target_profile.cpp`의 `ez2dj3rd` I/O 헬퍼 RVA 등록**:
   - `entry.profile.run_defaults.lptdi.legacy_io_in_byte_rva = 0x000a9887;`
   - `entry.profile.run_defaults.lptdi.legacy_io_out_byte_rva = 0x000a98bb;`
   - `entry.profile.run_defaults.lptdi.legacy_io_port_range_fallback = false;` (제거 또는 false)
   - 프로파일 설명 문구 갱신 (helper RVA 확정 반영).
4. **단위 테스트 갱신 및 신규 테스트 작성**:
   - `tests/unit/target_profile_test.cpp`: `ez2dj3rd`의 헬퍼 RVA 및 폴백 상태 검증 갱신.
   - `src/tools/windows_product_loader_probe/main.cpp`: 3rd의 런처 인자 검증(no `--hle-io-port-range`) 갱신.
   - `tests/unit/ez2dj_keyboard_input_test.cpp`: `Ez2DjKeyboardInput` 파싱 및 설정 파일 로딩 검증 테스트 작성.
   - `CMakeLists.txt`: 신규 테스트 등록.
5. **빌드 및 단위 테스트 검증**:
   - `scripts/build_release.bat -SkipTests`
   - `ctest --output-on-failure`
6. **실제 실행 및 입력 응답 검증**:
   - `re2dj.exe ez2dj3rd --io-config .\config\ez2dj-io.example.ini` 실행 후 코인 투입(F5), 스타트(1), 키 입력 동작 확인.
7. **작업 로그 작성 및 커밋**:
   - `docs/work-logs/20260906-218-ez2dj3rd-io-input.md` 작성.
   - 변경 사항 커밋.

## English

### Objective

Enable keyboard input (`--io-config`) for `ez2dj3rd` by extending key name parsing in `Ez2DjKeyboardInput`, canonicalizing the config file path to an absolute path, and configuring the confirmed I/O helper RVAs in the `ez2dj3rd` target profile.

### Detailed Tasks

1. **Extend `ParseKey` in `src/platform/windows/ez2dj_keyboard_input.cpp`**:
   - Add support for common keys including `TAB` (`VK_TAB`), `ESCAPE`/`ESC`, `LSHIFT`, `RSHIFT`, `SHIFT`, `LCONTROL`/`LCTRL`, `RCONTROL`/`RCTRL`, `CONTROL`/`CTRL`, `LMENU`/`LALT`, `RMENU`/`RALT`, `ALT`, `BACKSPACE`/`BACK`, `CAPITAL`/`CAPSLOCK`/`CAPS`, `INSERT`, `DELETE`/`DEL`, `HOME`, `END`, `PAGEUP`/`PGUP`, `PAGEDOWN`/`PGDN`.
2. **Canonicalize `io_config` Path to Absolute**:
   - `src/host/cli/main.cpp`: Convert `--io-config` argument to `std::filesystem::absolute`.
   - `src/platform/windows/original_process_backend.cpp`: Forward absolute path string to launcher probe.
   - `src/tools/windows_x86_launcher_probe/main.cpp`: Ensure `io_config_path` is canonicalized as absolute.
3. **Register `ez2dj3rd` I/O Helper RVAs in `src/target/target_profile.cpp`**:
   - `entry.profile.run_defaults.lptdi.legacy_io_in_byte_rva = 0x000a9887;`
   - `entry.profile.run_defaults.lptdi.legacy_io_out_byte_rva = 0x000a98bb;`
   - `entry.profile.run_defaults.lptdi.legacy_io_port_range_fallback = false;`
   - Update profile note reflecting confirmed helper RVAs.
4. **Update Unit Tests and Add New Unit Tests**:
   - `tests/unit/target_profile_test.cpp`: Update `ez2dj3rd` helper RVA and fallback expectations.
   - `src/tools/windows_product_loader_probe/main.cpp`: Update 3rd launcher argument checks (no `--hle-io-port-range`).
   - `tests/unit/ez2dj_keyboard_input_test.cpp`: Write unit tests validating `Ez2DjKeyboardInput` parsing and INI loading.
   - `CMakeLists.txt`: Register new test executable.
5. **Build and Unit Test Verification**:
   - `scripts/build_release.bat -SkipTests`
   - `ctest --output-on-failure`
6. **Live Execution Verification**:
   - Launch `re2dj.exe ez2dj3rd --io-config .\config\ez2dj-io.example.ini` and verify input response (Coin F5, Start 1, keys).
7. **Work Log and Commit**:
   - Write `docs/work-logs/20260906-218-ez2dj3rd-io-input.md`.
   - Commit all changes on the task branch.
