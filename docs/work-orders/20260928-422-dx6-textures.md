# 작업 422 작업 지시서 — Linux DX6 texture / Task 422 work order — DX6 textures on Linux

설계: [20260928-422-dx6-textures.md](../design/20260928-422-dx6-textures.md)

## 절차 / Steps

1. `abi.h`에 IID와 오류 값을 더하고, Windows에서 SDK 값과 대조한다.
   *Add the IID and error values to `abi.h`, checked against the SDK on Windows.*
2. `IDirect3DTexture2` 블록과 표면 `QueryInterface`, texture method, `IDirect3DDevice3::SetTexture`를 구현한다.
   *Implement the `IDirect3DTexture2` block, surface `QueryInterface`, the texture methods, and `IDirect3DDevice3::SetTexture`.*
3. Linux 1st SE를 실행하고, DirectDraw·Direct3D가 아닌 미구현 API가 나올 때까지 이어지는 DX 호출을 같은 방식으로 더한다.
   *Run Linux 1st SE and add the DX calls that follow the same way until an unimplemented API outside DirectDraw and Direct3D appears.*
4. 단위 테스트를 더하고 Linux 두 폭과 Windows에서 테스트한다.
   *Add unit tests and test on both Linux widths and Windows.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux 1st SE가 DX6 texture 경로를 지난다. 멈추는 곳은 작업 로그에 적는다.
  *Linux 1st SE gets past the DX6 texture path, with where it stops recorded in the work log.*
