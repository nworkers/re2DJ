# 작업 399 작업 지시서 — FindFirstFileA와 곡·스타일 목록 / Task 399 work order — FindFirstFileA and style listings

설계: [20260927-399-find-files.md](../design/20260927-399-find-files.md)

## 절차 / Steps

1. `FindFirstFileA`, `FindNextFileA`, `FindClose`를 Windows 11에서 측정한다.
   *Measure `FindFirstFileA`, `FindNextFileA`, and `FindClose` on Windows 11.*
2. 제품 VFS의 목록 규칙을 core로 옮기고 Windows가 쓰게 한다.
   *Move the product VFS's listing rules to the core and have Windows use them.*
3. `GuestFiles` 검색과 kernel32 세 export를 구현한다.
   *Implement the `GuestFiles` search and the three kernel32 exports.*
4. 단위 테스트, 실제 실행(코인·시작), Windows 전후 비교, 문서.
   *Unit tests, a real run (coins and start), a Windows before/after comparison, and documentation.*

## 완료 조건 / Done when

- Windows x86과 Linux 두 폭이 build와 CTest를 통과하고, Windows 실제 4th의 VFS·그래픽 기록이 작업 전과 같다.
  *Windows x86 and both Linux widths build and pass CTest, and the real 4th's VFS and graphics logs on Windows match the ones before the task.*
- Linux 실제 4th가 스타일 선택 뒤의 파일 검색을 지난다.
  *On Linux the real 4th gets past the file search after the style select screen.*
