# 작업 434 작업 지시서 — 6th의 Remember 1st 모드 / Task 434 work order — 6th's Remember 1st mode

설계: [20261001-434-remember-1st.md](../design/20261001-434-remember-1st.md)

## 절차 / Steps

1. launcher의 1st 분기와 1st 자식의 경계(reserved 검사, Hardlock API, 포트, INI)를 원본에서 확인하고, 1st 자식을 Linux에서 직접 실행해 멈추는 곳을 찾는다.
   *Confirm the launcher's 1st branch and the 1st child's boundaries (the reserved check, the Hardlock API, ports, INI) in the original, and run the 1st child directly on Linux to find where it stops.*
2. `WritePrivateProfileStringA`를 Windows 11에서 측정한다.
   *Measure `WritePrivateProfileStringA` on Windows 11.*
3. 공용 `target`(자식 실행 파일 목록, 자식 run의 작업 디렉터리와 module 경로), 공용 INI core의 갱신, Linux kernel32 `WritePrivateProfileStringA`, CLI staging과 옵션, Windows probe의 자식 반복과 `--startup-reserved`를 구현한다.
   *Implement the shared `target` (child executable list, a child run's working directory and module path), the INI core's update, the Linux kernel32 `WritePrivateProfileStringA`, the CLI staging and options, and the Windows probe's child loop and `--startup-reserved`.*
4. 단위 테스트를 만들고 세 host에서 테스트한다. Linux 두 폭과 Windows에서 1st 자식을 직접 실행해 확인하고, Windows에서 launcher를 거친 경로를 확인한다.
   *Add unit tests and test on all three hosts. Run the 1st child directly on both Linux widths and on Windows, and check the path through the launcher on Windows.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- 1st 자식이 세 host에서 launcher의 값을 받아 게임으로 들어가고, 시간 제한까지 멈추지 않는다.
  *The 1st child enters the game with the launcher's values on all three hosts and does not stop before the timeout.*
