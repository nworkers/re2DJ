# #12 작업 지시서 — 인자 없이 실행했을 때 띄우는 런처 / #12 work order — a launcher shown when run without arguments

이슈: [#12](https://github.com/reexec/re2DJ/issues/12) · 설계: [20261010-i012-launcher.md](../design/20261010-i012-launcher.md)

## 절차 / Steps

1. `FindChdImage`를 `main.cpp`에서 `re2dj/hdd/chd_image_locator.{h,cpp}`로 옮기고 단위 테스트를 단다.
   *Move `FindChdImage` from `main.cpp` to `re2dj/hdd/chd_image_locator.{h,cpp}` and add unit tests.*
2. `launcher_catalog.{h,cpp}`: 내장 프로필의 가용 여부와 사유. 단위 테스트.
   *`launcher_catalog.{h,cpp}`: availability and reasons for the built-in profiles, with unit tests.*
3. `launcher_settings.{h,cpp}`: `cfg/re2dj.ini` 읽기·쓰기, 자식 인자 목록. 단위 테스트.
   *`launcher_settings.{h,cpp}`: reading and writing `cfg/re2dj.ini` and the child's argument list, with unit tests.*
4. `self_process.h`와 Linux·Windows 구현(Windows는 기존 `QuoteCommandLineArgument` 사용).
   *`self_process.h` with Linux and Windows implementations (Windows using the existing `QuoteCommandLineArgument`).*
5. `ui/launcher_screen.{h,cpp}`(ImGui 화면)와 `platform/sdl/launcher_window.{h,cpp}`(SDL3 창·ImGui backend). CMake에 `imgui_impl_sdl3`를 쓰는 라이브러리를 추가한다.
   *`ui/launcher_screen.{h,cpp}` (the ImGui screen) and `platform/sdl/launcher_window.{h,cpp}` (the SDL3 window and ImGui backends); add a CMake library using `imgui_impl_sdl3`.*
6. `host/cli/launcher_session.{h,cpp}`와 `main.cpp` 배선(`RE2DJ_LAUNCHER=0`, 창을 열 수 없을 때의 기존 동작).
   *`host/cli/launcher_session.{h,cpp}` and the `main.cpp` wiring (`RE2DJ_LAUNCHER=0` and the existing behaviour when no window can open).*
7. 문서: `ARCHITECTURE.md`, README의 실행 방법, 사용법 출력, `THIRD_PARTY_NOTICES.md`(ImGui 항목 범위 확인), `docs/IMPLEMENTED.md`.
   *Documents: `ARCHITECTURE.md`, the README's running section, the usage text, `THIRD_PARTY_NOTICES.md` (check the ImGui entry's scope) and `docs/IMPLEMENTED.md`.*
8. 검증: Linux x64·x86 Debug(경고를 오류로)·Release 빌드와 CTest, 실제 실행(목록, 6th 실행과 복귀, 설정 저장·반영, `RE2DJ_LAUNCHER=0`, 디스플레이 없음), push 뒤 CI.
   *Verification: Linux x64 and x86 Debug (warnings as errors) and Release builds with CTest, real runs (the list, running 6th and returning, settings saved and applied, `RE2DJ_LAUNCHER=0`, no display), and CI after the push.*

## 완료 조건 / Done when

인자 없이 실행한 `re2dj`가 런처를 띄우고, 고른 프로필을 새 프로세스로 실행한 뒤 런처로 돌아오며, 옵션이 저장되고 다음 실행에 반영된다. 인자를 준 실행은 그대로이고, 단위 테스트와 모든 타깃 빌드가 통과한다.

*Run bare, `re2dj` opens the launcher, runs the chosen profile in a new process and returns to the launcher, and options are saved and applied to the next run; runs with arguments are unchanged, and the unit tests and every target's build pass.*
