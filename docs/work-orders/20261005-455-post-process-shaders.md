# 작업 455 작업 지시서 — 화면 후처리 셰이더 / Task 455 work order — post-processing shaders

설계: [20261005-455-post-process-shaders.md](../design/20261005-455-post-process-shaders.md)

## 절차 / Steps

1. GL 없는 모듈: `post_shader_source`, `post_shader_catalog`, `post_shader_control.h`를 `re2dj_legacy_graphics`에 더하고, 내장 셰이더 두 개와 생성 헤더 틀을 `src/graphics/post_shaders/`에 둔다. CMake가 configure 때 생성 헤더를 만든다.
   *GL-free modules `post_shader_source`, `post_shader_catalog` and `post_shader_control.h` in `re2dj_legacy_graphics`; the two built-ins and the generated-header template in `src/graphics/post_shaders/`, the header generated by CMake at configure time.*
2. GL 모듈 `opengl_post_process`를 `re2dj_sdl3_opengl_backend`에 더하고, backend의 `Initialize`·`Present`·소멸에 연결한다. `Sdl3OpenGlWindowConfig::post_shader`로 처음 셰이더를 받는다.
   *The GL module `opengl_post_process` in `re2dj_sdl3_opengl_backend`, wired into the backend's `Initialize`, `Present` and teardown, with `Sdl3OpenGlWindowConfig::post_shader` carrying the first shader.*
3. OSD에 셰이더 메뉴(콤보, Reload, 오류, 매개변수 슬라이더), SDL host에 선택 전달과 로그, CLI에 `--post-shader`와 `RE2DJ_POST_SHADER`.
   *The OSD's shader menu (combo, Reload, errors, parameter sliders), selection and logging in the SDL host, and `--post-shader` with `RE2DJ_POST_SHADER` in the CLI.*
4. 단위 테스트와 GL probe `re2dj_opengl_post_shader_probe`.
   *Unit tests and the GL probe `re2dj_opengl_post_shader_probe`.*
5. 문서: 가이드 `docs/guides/post-process-shaders.md`, kb `docs/kb/libretro-glsl-post-shaders.md`, 두 색인, README(옵션·셰이더 절), ARCHITECTURE(표시 경로), `THIRD_PARTY_NOTICES.md`·`CREDITS.md` 확인.
   *Documents: the guide, the kb topic, both indexes, the README (option and shader section), ARCHITECTURE (presentation path), and a check of `THIRD_PARTY_NOTICES.md` and `CREDITS.md`.*
6. 검증: Windows x86 Debug·Release, WSL Linux x64(gcc·clang)·x86, CTest, GL probe, 실제 게임 실행.
   *Verification: Windows x86 Debug and Release, WSL Linux x64 (gcc, clang) and x86, CTest, the GL probe, real game runs.*
