# 작업 424 작업 지시서 — IDirectDrawSurface7::Lock / Unlock / Task 424 work order — IDirectDrawSurface7::Lock and Unlock

설계: [20260929-424-surface-lock.md](../design/20260929-424-surface-lock.md)

## 절차 / Steps

1. 사용자 로그(`re2dj_log.txt`)에서 멈춘 곳을 확인한다.
   *Find where the run stopped in the user's log (`re2dj_log.txt`).*
2. Windows facade의 Lock 규칙을 공용 core로 옮기고, Linux Lock/Unlock을 구현한다.
   *Move the Windows facade's Lock rules to the shared core and implement Linux Lock/Unlock.*
3. core와 모듈 단위 테스트를 만든다. Linux 두 폭과 Windows에서 테스트하고, 두 host의 4th에서 F1을 눌러 비교한다.
   *Add core and module unit tests, test on both Linux widths and Windows, and compare pressing F1 in 4th on both hosts.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux 4th가 F1 뒤에도 멈추지 않고, Windows와 같은 화면을 보인다.
  *Linux 4th no longer stops after F1 and shows what Windows shows.*
