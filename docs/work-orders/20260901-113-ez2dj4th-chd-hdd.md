# ez2dj4th CHD HDD 입력 작업 지시

## 한국어

관련 설계: [ez2dj4th CHD HDD 입력 설계](../design/20260901-113-ez2dj4th-chd-hdd.md)

### 작업 범위

1. 현재 target profile 자료구조에 HDD 입력 종류와 CHD 기본 경로를 추가한다.
2. `ez2dj4th` built-in profile을 `roms/ez2dj4th` shortcut으로 등록한다. 원본 실행 파일 지문은 확인 전까지 임의로 확정하지 않으며, CHD 입력 선언과 미확정 note를 분리한다.
3. `libchdr`를 vendoring하고 공용 storage adapter에서 header, metadata, map, codec, hunk read를 호출한다.
4. 실제 CHD를 읽는 비실행 분석 도구와 단위 테스트를 추가한다.
5. CMake, ARCHITECTURE, README, TODO/IMPLEMENTED 및 third-party 고지를 갱신하고 작업 로그를 작성한다.

### 제외 범위

이번 작업에서는 CHD 내부 FAT/exFAT 디렉터리 열거, 기존 `HddRoot` VFS에 대한 완전한 mount, 원본 PE 실행 연결, CHD 쓰기/overlay를 구현하지 않는다. 이 경계는 다음 작업의 입력으로 기록한다.

### 완료 조건

* `FindBuiltInTargetProfileById("ez2dj4th")`가 `HddInputKind::kMameChd`와 `roms/ez2dj4th`를 반환한다.
* adapter의 잘못된 범위 단위 테스트가 통과한다.
* 사용자가 제공한 실제 CHD를 probe가 열고 geometry metadata와 LBA 0의 512 bytes를 읽는다.
* 원본 자산이 Git diff에 포함되지 않는다.
* 공용 unit test와 범위에 맞는 build가 통과한다.

## English

Related design: [ez2dj4th CHD HDD input design](../design/20260901-113-ez2dj4th-chd-hdd.md)

Add an input-kind field and CHD shortcut to target profiles, register `ez2dj4th` with `roms/ez2dj4th`, vendor libchdr behind a platform-neutral storage adapter, and add a real-CHD probe plus tests. FAT enumeration, complete VFS mounting, PE execution, writes, and overlay remain explicitly out of scope for this task.
