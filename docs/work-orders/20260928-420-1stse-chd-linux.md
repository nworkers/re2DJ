# 작업 420 작업 지시서 — Linux에서 1st SE CHD 실행 / Task 420 work order — running the 1st SE CHD on Linux

설계: [20260928-420-1stse-chd-linux.md](../design/20260928-420-1stse-chd-linux.md)

## 절차 / Steps

1. Linux x64·x86에서 `re2dj --run ez2dj1stse`를 실행해 첫 경계를 찾는다.
   *Run `re2dj --run ez2dj1stse` on Linux x64 and x86 and find the first boundary.*
2. 멈추는 경계마다 동작을 확인하고, 공용 HLE와 단위 테스트를 더하고, 설계의 진행 기록에 적는다.
   *For each stopping boundary, confirm the behavior, add the shared HLE and unit tests, and record it in the design's progress section.*
3. Linux 두 폭과 Windows에서 테스트한다.
   *Test on both Linux widths and Windows.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux 1st SE가 창을 닫을 때까지 실행된다. 그러지 못하면 멈춘 곳과 이유를 작업 로그에 적는다.
  *Linux 1st SE runs until its window is closed, or where and why it stops is recorded in the work log.*
