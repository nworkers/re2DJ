# Windows x86 Native Host Policy

## 한국어

1. Win32 x86 full-host CMake preset을 추가합니다.
2. Windows build/test script 기본 preset을 x86으로 바꿉니다.
3. 프로젝트 헌장, architecture, TODO, porting plan과 script index에 x86 우선·x64 보류 정책을 반영합니다.
4. warnings-as-errors Win32 build와 CTest를 실행합니다.

## English

1. Add a Win32 x86 full-host CMake preset.
2. Change Windows build/test script defaults to x86.
3. Reflect the x86-first/x64-deferred policy in the charter, architecture, TODO, porting plan, and script index.
4. Run a warnings-as-errors Win32 build and CTest.
