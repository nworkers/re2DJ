1. canonical 1st SE profile이 가리키는 `ez2dj.exe`를 launcher 기본값으로 사용한다.
2. `bring_up_target` profile을 launcher의 실행·관찰 대상에서 제외하지 않는다.
3. 실제 `roms/ez2dj1stse` 입력으로 entry stop 또는 관찰 경로를 검증한다.
4. 분석, TODO, 작업 로그를 확인 결과에 맞춰 갱신한다.

## English

1. Use the `ez2dj.exe` referenced by the canonical 1st SE profile as the launcher default.
2. Do not exclude a `bring_up_target` profile from launcher execution or observation.
3. Verify the entry-stop or observation path with the live `roms/ez2dj1stse` input.
4. Update analysis, TODO, and the work log according to the result.
