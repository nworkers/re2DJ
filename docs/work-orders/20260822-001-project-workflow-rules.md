rePIU의 작업 규칙을 기준으로 re2DJ의 핵심 원칙, 응답 태도, 요구사항 처리 절차, 문서 작성 규칙, 원본 자산 취급 규칙, 구현 규칙, 작업 단위 규칙, Git 작업 규칙, 아키텍처 규칙을 `AGENTS.md`와 관련 기준 문서에 반영한다.

## 범위

* `AGENTS.md` 작성
* `CLAUDE.md` 작성
* `docs/PROJECT_CHARTER.md` 추가
* `docs/CODING_STYLE.md` 추가
* `docs/EXE_DESIGN.ko.md` 및 `docs/EXE_DESIGN.en.md` 추가

* `AGENTS.md`의 디렉터리 규칙과 실제 디렉터리 구조가 일치하는지 확인한다.
* 라이선스 정책과 `LICENSE` 파일 내용이 어긋나지 않는지 확인한다.

## Work Order: Project Workflow Rules

## Goal

Using rePIU's rules as the baseline, record re2DJ's core principles, response tone, requirement handling procedure, documentation rules, original-asset handling rules, implementation rules, task unit rules, Git workflow rules, and architecture rules in `AGENTS.md` and the related baseline documents.

## Scope

Write `AGENTS.md` and `CLAUDE.md`; add `docs/PROJECT_CHARTER.md`, `docs/CODING_STYLE.md`, the two `EXE_DESIGN` documents, the `analysis`, `kb`, and `guides` indexes, `LICENSE`, `THIRD_PARTY_NOTICES.md`, and `VERSION`; and add the task documents under `docs/design/`, `docs/work-orders/`, and `docs/work-logs/`.

## Verification

Confirm the documents exist, that the directory rules in `AGENTS.md` match the real directory structure, and that the license policy and the `LICENSE` file agree.
