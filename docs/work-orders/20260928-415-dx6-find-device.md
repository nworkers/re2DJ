# 작업 415 작업 지시서 — IDirect3D3::FindDevice를 공용 core로 / Task 415 work order — IDirect3D3::FindDevice on a shared core

설계: [20260928-415-dx6-find-device.md](../design/20260928-415-dx6-find-device.md)

## 절차 / Steps

1. DX6 구조체와 `FindDevice`를 공용 core에 두고, SDK와의 배치 검사를 더한다.
   *Put the DX6 structures and `FindDevice` in the shared core, with layout checks against the SDK.*
2. Windows facade를 core로 바꾸고 Linux handler를 구현한다.
   *Switch the Windows facade to the core and implement the Linux handler.*
3. 단위 테스트, Windows 1st 짧은 실행, Linux 1st 실행, 문서.
   *Unit tests, a short Windows 1st run, a Linux 1st run, and documentation.*

## 완료 조건 / Done when

- Windows x86과 Linux 두 폭이 build와 테스트를 통과한다.
  *Windows x86 and both Linux widths build and pass their tests.*
- Windows 1st가 전처럼 `FindDevice` 뒤 `CreateDevice`로 가고, Linux 1st가 `FindDevice`를 지난다.
  *Windows 1st still goes from `FindDevice` to `CreateDevice`, and Linux 1st gets past `FindDevice`.*
