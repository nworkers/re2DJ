# 작업 427 작업 지시서 — Linux에서 EZ2Dancer 2nd MOVE 실행 / Task 427 work order — running EZ2Dancer 2nd MOVE on Linux

설계: [20260929-427-ez2d2m-linux.md](../design/20260929-427-ez2d2m-linux.md)

## 절차 / Steps

1. 사용자 로그에서 멈춘 곳을 확인하고, 원본 import 이름 전체를 복호화 이미지에서 모은다.
   *Find the stop in the user's log and collect every original import name from the decrypted image.*
2. 경계를 차례로 고친다. 새 Windows 동작은 측정한다.
   *Fix each boundary in turn, measuring new Windows behaviour.*
3. 단위 테스트를 만든다. Linux 두 폭과 Windows에서 테스트하고, ez2d2m을 두 폭에서 실행해 화면을 확인한다.
   *Add unit tests, test on both Linux widths and Windows, and run ez2d2m on both widths, checking the screen.*

## 완료 조건 / Done when

- 모든 build와 테스트가 통과한다.
  *Every build and test passes.*
- Linux ez2d2m이 두 폭에서 타이틀 화면까지 가고, 창을 닫을 때까지 멈추지 않는다.
  *Linux ez2d2m reaches its title screen on both widths and runs until its window is closed.*
